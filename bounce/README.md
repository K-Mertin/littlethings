# 彈彈球大冒險 · Bounce Quest

橫向捲軸闖關＋解謎。玩家是一顆紅色的球：滾動、跳躍、變大變小，收集金色圈圈打開終點門。
靈感：Super Mario 的跳台闖關＋Nokia 經典手機遊戲 Bounce 的「控制一顆球過關」。
畫面全部用 Canvas 2D 程式畫（沒有圖片素材、沒有外部套件、沒有建置步驟）。
對象：小學中年級以上到大人（不是給幼兒的）。

## 玩法
- ← → 滾動（有慣性），空白鍵／↑／W 跳（按住跳比較高）。R 重來、Esc 暫停、Enter 開始／下一關。
- 觸控裝置：左下 ◀ ▶，右下大顆的 ⤒ 跳。
- 每關要收集全部 **金色圈圈** 才開門（沒有圈圈的關卡門一開始就開著）。
- **星星** 每關 3 顆，選收，過關畫面顯示幾顆；選關畫面有總星數。
- 碰到刺、岩漿、火焰棒、刺刺蝟、從側面撞到怪獸、掉出地圖 → 回到最後一支 **存檔旗子**。不限次數。

## 4 個世界、12 關
| 關 | 名稱 | 新東西 |
|---|---|---|
| 1-1 | 滾滾出發 | 滾、跳、洞、台階、浮空磚、存檔旗、門 |
| 1-2 | 金色圈圈 | 圈圈開門、地上刺、天花板刺（只能用滾的過）、踩扁小怪獸 |
| 1-3 | 彈簧與機關 | 彈簧、開關＋柵欄（藍／紫）、會掉的磚、移動平台、刺中間的彈簧 |
| 2-1 | 變大變小 | ＋ 變大（浮在水上、鑽不進窄洞）、− 變回一般（會沉）、井底拿圈圈 |
| 2-2 | 推箱子 | 箱子墊腳、箱子壓壓板、箱子從高台推下去、箱子推到刺上當墊腳石、刺刺蝟 |
| 2-3 | 潮汐浮島 | 上下移動的平台、水底洞穴（小球鑽、大球浮上來）、蝙蝠 |
| 3-1 | 冰晶滑道 | 冰（會滑、很難停）、冰柱尖刺、冰上的怪獸 |
| 3-2 | 風之洞窟 | 風扇（把一般球往上吹；大球太重吹不動）、刺上面的風扇鏈、會掉的橋＋蝙蝠 |
| 3-3 | 熔岩深處 | 岩漿、火焰棒（短 R／長 Q）、平台過岩漿、彈簧上高台、會掉的橋 |
| 4-1 | 雲端之路 | 下面是天空：升降台、風扇、會掉的磚、蝙蝠、火焰棒 |
| 4-2 | 機關城堡 | 藍／紫／綠三組機關的順序解謎、火焰走廊、塔頂火焰棒 |

洞窟世界畫面比較暗，只有球附近亮。

## 檔案
- `index.html`：版面、HUD、選關（分世界）／過關／暫停畫面、觸控按鈕（CSS 在這裡）。
- `levels.js`：**關卡資料**＋世界清單（`BOUNCE_WORLDS`）。每關一張字元地圖（一格 40px），字元對照寫在檔案開頭。改關卡只要改這裡。
- `game.js`：物理、碰撞、機關、繪圖（地形貼圖預先畫好快取、四種主題的視差背景）、輸入、存檔。

## 物理數字（`game.js` 的 `PHY`）
- 一般球：半徑 17、最高速 260、跳 620 → 大約跳 2.6 格高、跑跳最遠約 4 格。
- 大球：半徑 29（需要 2 格高的空間）、最高速 215、跳 570。浮力讓它浮在水面一半左右。
- 一般球在水裡：重力 0.4 倍、最快下沉 170、只有站在水底才能跳（跳不出 4 格深的井）。
- 彈簧 1050 → 大約 7.5 格高。風扇往上吹最多 7 格，大球只會變輕不會飛。
- 冰上加速 0.3 倍、摩擦 0.05 倍。
- 設計關卡時：一般球能上 2 格的台階，3 格要靠箱子或彈簧；同高度的洞 3 格以內比較友善，4 格是極限。

## 存檔
localStorage `bounce.v1`：`{ unlocked, levels: { <id>: { stars, time } }, mute }`。
關卡 id 就是 1–12 的順序。加欄位要相容舊存檔。

## 測試
`window.__bounce` 是給 Playwright 用的小把手：`start(i)`、`step(n)`（固定 1/120 秒）、`keys`、`jump()`、
`hold = true`（暫停自動更新，改用 `step` 手動推）、`fast = true`（關掉音效和粒子）、`snap()`（攝影機對準球）、
`snapshot()`／`restore(s)`（存／讀整個關卡狀態）。
上架前用 best-first 搜尋（真實物理、每個動作 0.125 秒、加一個「等 0.5 秒」）確認 12 關都能拿完圈圈過關。
