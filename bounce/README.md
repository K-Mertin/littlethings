# 彈彈球大冒險 · Bounce Quest

橫向捲軸闖關＋解謎。玩家是一顆紅色的球：滾動、跳躍、變大變小，收集金色圈圈打開終點門。
靈感：Super Mario 的跳台闖關＋Nokia 經典手機遊戲 Bounce 的「控制一顆球過關」。
畫面全部用 Canvas 2D 畫形狀，沒有圖片素材、沒有外部套件、沒有建置步驟。

## 玩法
- ← → 滾動（有慣性），空白鍵／↑／W 跳（按住跳比較高）。R 重來、Esc 暫停。
- 觸控裝置：左下 ◀ ▶，右下大顆的 ⤒ 跳。
- 每關要收集全部 **金色圈圈** 才開門（沒有圈圈的關卡門一開始就開著）。
- **星星** 每關 3 顆，可收可不收，過關畫面顯示幾顆。
- 碰到刺、刺刺蝟、從側面撞小怪獸、掉出地圖 → 回到最後一支 **存檔旗子**。不限次數。

## 機制（每關教一樣）
| 關 | 名稱 | 新東西 |
|---|---|---|
| 1 | 滾滾出發 | 滾、跳、洞、台階、存檔旗、門 |
| 2 | 金色圈圈 | 圈圈開門、地上刺、天花板刺（不能跳）、可以踩扁的小怪獸 |
| 3 | 彈簧與機關 | 彈簧、開關＋柵欄（藍／紫兩組）、會掉的磚、移動平台 |
| 4 | 變大變小 | ＋ 變大球（浮在水上、鑽不進窄洞）、− 變回一般（會沉）、水 |
| 5 | 推箱子 | 箱子（墊腳、壓壓板）、壓板（壓著才開）、刺刺蝟（不能踩） |
| 6 | 綜合大冒險 | 全部混在一起 |

## 檔案
- `index.html`：版面、HUD、選關／過關／暫停畫面、觸控按鈕（CSS 在這裡）。
- `levels.js`：**關卡資料**。每關一張字元地圖（一格 40px），字元對照寫在檔案開頭。改關卡只要改這裡。
- `game.js`：物理、碰撞、機關、繪圖、輸入、存檔。

## 物理數字（`game.js` 的 `PHY`）
- 一般球：半徑 17、最高速 260、跳 620 → 大約跳 2.6 格高、跑跳最遠約 4 格。
- 大球：半徑 29（需要 2 格高的空間）、最高速 215、跳 570。浮力讓它浮在水面一半左右。
- 一般球在水裡：重力 0.4 倍、最快下沉 170、只有站在水底才能跳（跳不出 4 格深的井）。
- 彈簧 1050 → 大約 7 格高。
- 設計關卡時：一般球能上 2 格的台階，3 格要靠箱子或彈簧；洞寬 3 格以內比較友善。

## 存檔
localStorage `bounce.v1`：`{ unlocked, levels: { <id>: { stars, time } }, mute }`。
加欄位要相容舊存檔。

## 測試
`window.__bounce` 是給 Playwright 用的小把手：`start(i)`、`step(n)`（固定 1/120 秒）、`keys`、`jump()`、`hold = true`（暫停自動更新，改用 `step` 手動推）、`snap()`（攝影機對準球）。
