# ABC Island（ABC 小島）

給幼兒園孩子（約 5 歲、已認得字母）的英文遊戲。小狐狸 Pip 用語音帶著孩子玩，不需要識字。所有東西都在 `index.html` 一個檔案裡：沒有建置步驟、沒有圖片或音檔、不需要任何函式庫（只從 Google Fonts 載入字型，離線時會改用系統字型）。

平板優先（Android 平板橫放或直放都可以），手機和電腦也能玩。

## 活動
| 首頁按鈕 | 內容 |
|---|---|
| ✏️ Write | 描 26 個小寫字母。每個字母三個階段：跟著虛線和箭頭描 → 只有淡淡的字 → 自己寫。有綠色起點和筆順，按 👀 可以看示範。每階段一顆星 |
| 🔤 Sounds | 看圖聽單字，找出開頭的字母（sun → s）。答錯會再示範一次，正確答案會發亮，並在這一輪稍後再考一次 |
| 🧩 Spell | 看圖拼三個字母的單字（cat、dog、sun…），拼完會一個字母一個字母唸出來。格子裡有淡色提示字（可在家長區關閉） |
| 🖼️ Words | 單字圖卡：動物、水果、顏色、數字 1–10、身體、交通工具。Pip 說一個字，點出正確的圖 |
| 💬 Talk | 和 Pip 用英文聊天的六個情境：打招呼、顏色、動物、點心、數數、天氣。可以點圖片回答，也可以按 🎤 用說的 |
| 🏝️ My Island | 每完成一輪得到一張貼紙，貼在自己的小島上。點貼紙會唸出英文，也可以拖著移動 |

任何時候點 Pip，他會再說一次題目。

## 設計原則
- 語音優先：說明都由 Pip 用英文說，第一次會接一句中文提示（可關）。
- 不懲罰：沒有扣分、沒有倒數、沒有失敗畫面；答錯就再示範一次。
- 大按鈕（至少 64px），只用點和畫。
- 預設 15 分鐘提醒休息。

## 家長區
按住右上角的 ⚙️ 兩秒，再答一題加法，就能進入：
- 進度：貼紙、每個字母的星星、拼過的單字、需要多練的開頭音、今天玩了多久
- 設定：中文提示、提示字、英文語速、英文聲音、麥克風、休息提醒、全螢幕、清除進度、回遊戲大廳

進度存在瀏覽器的 localStorage。

## 語音
- 說話用瀏覽器內建的 Web Speech（`speechSynthesis`）。Android 平板請確認已安裝「Google 文字轉語音」的英文語音；若要中文提示，也安裝中文（台灣）語音。
- 聊天的 🎤 用 `SpeechRecognition`（Android 的 Chrome、桌機 Chrome、Safari 支援）。只比對關鍵字，聽不懂就讓孩子選圖片，不判錯。Chrome 的語音辨識會把聲音送到 Google 處理；遊戲本身不錄音、不儲存任何聲音或對話。
- 語音辨識需要 https 或 localhost（GitHub Pages 可以）。

## 遊玩
```sh
python3 -m http.server 8000   # 在 littlethings 根目錄，然後打開 http://localhost:8000/abc/
```
