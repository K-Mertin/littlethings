# 砰砰小隊 · Boom Buddies

放炸彈、炸木箱、躲火焰的格子迷宮遊戲（經典炸彈人玩法，角色和美術都是自己畫的）。
畫面全部用 Canvas 2D 程式畫，沒有圖片素材、沒有外部套件、沒有建置步驟。

## 玩法
- 場地 13×11 格。炸彈 2.4 秒後爆炸，火焰往四個方向衝，碰到石柱停下、炸掉第一個木箱後停下；火焰碰到別的炸彈會連鎖引爆。
- **闖關冒險**：3 個世界（青草原、雪花谷、火山口）各 8 關，共 24 關，每個世界最後一關是大王。
  把怪物全部炸掉 → 出口打開（出口藏在某個木箱底下；怪物清光還沒找到時，那個木箱會閃 ✨）→ 走進出口過關。
  3 顆心；星星：過關 1 顆、沒受傷 +1、在三星時間內 +1。限時 5 分鐘。過了一關才開下一關。
- **對戰**：1～2 個人（同一個鍵盤，或同一台平板）＋電腦，最多 4 個角色；電腦強度弱／普通／強；先贏 1／2／3／5 回合。
  70 秒後場地從外圈開始掉石頭（驟死）。人都出局後只剩電腦時會自動快轉。
- **小朋友模式**（主選單開關）：闖關時自己的炸彈不會炸到自己、5 顆心、沒有時間限制。
- 道具（藏在木箱裡，被火焰燒到會消失）：💣 多一顆炸彈、🔥 火焰 +1 格、👟 加速（最多 3 雙）、🥾 可以把炸彈踢走、🛡️ 擋一次傷害、❤️ 補一顆心（闖關才有）。
- 怪物：史萊姆（慢、直直走）、蝙蝠（快、亂飛）、幽靈（會穿過木箱）、小惡魔（會追人）、大王（要炸好幾下）。

## 操作
- 一個人：方向鍵或 WASD 走路，空白鍵（或 Enter／X／J）放炸彈。
- 兩個人：1P WASD＋空白鍵（或 F），2P 方向鍵＋Enter（或 `/`、`.`、右 Shift）。
- 觸控：畫面左半邊滑動是搖桿（按下的地方就是中心），右下角 💣；點畫面右半邊也會放炸彈。
- 兩個人用同一台觸控裝置（對戰選 2 個人）：畫面左半邊是 1P、右半邊是 2P，各有自己的浮動搖桿和 💣 鈕（`#stick`／`#stick2`、`#bBomb`／`#bBomb2`）。
- Esc／P 暫停。選單畫面 Esc 回上一頁，主選單 Esc 回大廳。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 版面、樣式、選單 |
| `core.js` | 規則：場地產生、移動（含轉角輔助）、炸彈與火焰、道具、怪物、電腦對手、驟死。不碰 DOM，瀏覽器和 node 共用 |
| `game.js` | 繪圖、鍵盤與觸控、音效（WebAudio 合成）、選單流程、存檔 |
| `tools/sim.mjs` | 模擬器：電腦互打＋電腦自動玩 24 關 |

關卡定義在 `core.js` 的 `STAGES`（怪物組合、木箱密度、道具、場地樣式），場地用固定種子產生，所以每一關的地形每次都一樣。

## 驗證
```sh
node boom/tools/sim.mjs        # 改了 core.js 就跑：對戰都要能結束、24 關都要有通關紀錄
```
網址加 `?auto=1` 會讓電腦代玩闖關（測試用）。`window.__boom` 可以看目前的狀態。

## 存檔
localStorage `boom:v1`：`{ stars: [每關星數], kid: 小朋友模式, mute: 靜音, bt: { h 人數, b 電腦數, l 強度, w 先贏幾回合 } }`。
加欄位要相容舊存檔。
