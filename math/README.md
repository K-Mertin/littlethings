# 123 小島

給幼兒園孩子的數學遊戲（數數 → 加減乘除入門，27 課）（ABC Island、ㄅㄆㄇ 小島的姊妹作）。台灣黑熊「小黑」用台灣腔的語音念題目，不需要識字。平板優先（橫放直放都可以），手機、電腦也能玩；只用點的，按鈕夠大；沒有扣分、倒數或失敗畫面。

名字和吉祥物是暫定的。

## A. 數與量（第一段）
| 課 | 內容 |
|---|---|
| 1 數到 5 | 1–5 個東西排一排。點一下數一個（東西上出現數字、小黑念出來），數完會說「一共有三顆蘋果」。從三個數字裡選答案，數字下面有小圓點幫忙 |
| 2 數到 10 | 6–10 個東西排在兩排五格裡（像十格框），偶爾混一題小的 |
| 3 數量配對 | 聽數字、看大數字，從三盤裡找出一樣多的那一盤；有時候東西排整齊，有時候散在格子裡 |
| 4 認數字 | 聽「七在哪裡？」點數字 0–10。認得以後會混進長得像的（6／9、1／7、3／8、2／5） |
| 5 比多少 | 哪一盤比較多、哪一盤比較少、哪一盤和上面這盤一樣多。一開始兩盤差比較多，之後差 1 |
| 6 排順序 | 數字小火車：下一個是幾、少了哪一個、把亂掉的數字照順序點回車廂 |
| 7 數到 20 | 一盒裝十顆（十格盒）＋外面幾顆。點盒子念「一盒是十」，再往下數十一、十二… |

- 一輪 6 題，完成送一張貼紙（40 種）；每課最多顯示三顆星（玩過幾輪）
- 答錯：小黑「我們一起數一數」，一個一個亮起來念給孩子聽，再請孩子點發亮的答案；這題稍後換個樣子再出一次（一輪最多 2 題）
- 答錯過的數字或題型會比較常出現
- 任何時候點小黑，他會再說一次

## B–G 加減乘除入門（第二段）
| 單元 | 課 | 內容 |
|---|---|---|
| B 分與合 | 8 5 的分合、9 6–9 的分合 | 上面是總數，一邊看得到、另一邊蓋起來，猜藏了幾個。答錯會打開蓋子接著數 |
| | 10 湊十 | 十格框裝了幾個，還要幾個才會滿。答錯一格一格補滿 |
| C 加法 | 11 5 以內加法 | 小故事：「有三隻小雞，又跑來了兩隻」，東西一個一個跑進來，問現在有幾隻 |
| | 12 10 以內加法 | 同上，再加上算式 3 + 2 = ? |
| | 13 加法算式 | 只有算式；答錯才畫出紅點、藍點一起數 |
| | 14 加法小祕訣 | 加 0、加 1、雙倍（3 + 3），答完說小祕訣 |
| | 15 數線跳跳 | 青蛙停在 a，加幾就往前跳幾格 |
| D 減法 | 16 5 以內減法、17 10 以內減法（＋算式） | 「有五顆蘋果，拿走了兩顆」，拿走的變灰、打叉，數剩下的 |
| | 18 減法算式、19 減法小祕訣 | 減 0、減 1、全部拿走 |
| E 加減一起 | 20 加還是減 | 聽完故事先選＋還是－，再算答案 |
| | 21 小故事 | 加減混在一起的小故事 |
| | 22 20 以內加法 | 十格盒先裝滿（9 + 3：先補一個變十），再往下數十一、十二 |
| F 乘法入門 | 23 幾個一盤 | 「有三盤，每盤兩顆」，一盤一盤跳著數（二、四、六） |
| | 24 跳著數 | 袋鼠火車：2、5、10 個一數，下一個是幾、少了哪個 |
| | 25 乘法算式 | 盤子圖＋算式 2 × 3（每盤 2 顆、3 盤；台灣課本的寫法） |
| G 除法入門 | 26 平分 | 點一下東西就分給下一隻小熊；問每隻小熊有幾顆 |
| | 27 除法算式 | 同上，加上算式 6 ÷ 2 |

- 為了少錄一點音，加減乘除的題目只用「顆」和「隻」的東西；乘除只用食物（蘋果、草莓、糖果）
- 錄音：edge-tts 有時會擋太頻繁的請求，`tools/record.py` 會等一等再重試（`TTS_JOBS` 可以調同時錄幾句）

## 家長區
按住右上角 ⚙️ 兩秒，再答一題加法：今天玩了多久、貼紙、每課玩了幾輪、答對答錯、常錯的數字或題型；休息提醒（預設 15 分鐘）、全螢幕、清除進度。進度存在瀏覽器的 localStorage（`math-v1`）。

## 語音
- 台詞都寫在 `data.js` 的 `P`，`allLines()` 列出每一句；`node tools/lines.js > audio/phrases.tsv`
- 音檔用 `tools/record.py`（edge-tts 的台灣男聲 zh-TW-YunJheNeural 雲哲，語速 +5%，ffmpeg 剪掉前後靜音；2026-10-21 從曉臻 -10% 換過來，因為 MK 覺得太慢、不夠自然）。換聲音要先刪掉 audio/*.mp3 再錄，檔名是文字的 FNV-1a 雜湊。只錄還沒有的句子
- 量詞照實際用法（兩顆蘋果、三隻小狗、一條小魚、一根香蕉、一台小汽車、一朵花）
- 聲音授權的狀況同 ㄅㄆㄇ 小島（自己家用）
