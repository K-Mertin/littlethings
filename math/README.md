# 123 小島

給幼兒園孩子的數學遊戲（數數 → 加減乘除、形狀、時鐘、錢幣、二位數，64 課＋7 款小遊戲）（ABC Island、ㄅㄆㄇ 小島的姊妹作）。小白兔「小白」用台灣腔的語音念題目，不需要識字。平板優先（橫放直放都可以），手機、電腦也能玩；只用點的，按鈕夠大；沒有扣分、倒數或失敗畫面。

名字和吉祥物是暫定的。

## A. 數與量（第一段）
| 課 | 內容 |
|---|---|
| 1 數到 5 | 1–5 個東西排一排。點一下數一個（東西上出現數字、小白念出來），數完會說「一共有三顆蘋果」。從三個數字裡選答案，數字下面有小圓點幫忙 |
| 2 數到 10 | 6–10 個東西排在兩排五格裡（像十格框），偶爾混一題小的 |
| 3 數量配對 | 聽數字、看大數字，從三盤裡找出一樣多的那一盤；有時候東西排整齊，有時候散在格子裡 |
| 4 認數字 | 聽「七在哪裡？」點數字 0–10。認得以後會混進長得像的（6／9、1／7、3／8、2／5） |
| 5 比多少 | 哪一盤比較多、哪一盤比較少、哪一盤和上面這盤一樣多。一開始兩盤差比較多，之後差 1 |
| 6 排順序 | 數字小火車：下一個是幾、少了哪一個、把亂掉的數字照順序點回車廂 |
| 7 數到 20 | 一盒裝十顆（十格盒）＋外面幾顆。點盒子念「一盒是十」，再往下數十一、十二… |

- 一輪 6 題，完成送一張貼紙（40 種）；每課最多顯示三顆星（玩過幾輪）
- 答錯：小白「我們一起數一數」，一個一個亮起來念給孩子聽，再請孩子點發亮的答案；這題稍後換個樣子再出一次（一輪最多 2 題）
- 答錯過的數字或題型會比較常出現
- 任何時候點小白，他會再說一次

## B–G 加減乘除入門（第二段）
| 單元 | 課 | 內容 |

| | 12 10 以內加法 | 同上，再加上算式 3 + 2 = ? |
| | 13 加法算式 | 只有算式；答錯才畫出紅點、藍點一起數 |
| | 14 加法小祕訣 | 加 0、加 1、雙倍（3 + 3），答完說小祕訣 |
| | 15 數線跳跳 | 青蛙停在 a，加幾就往前跳幾格 |
| D 減法 | 16 5 以內減法、17 10 以內減法（＋算式） | 「有五顆蘋果，拿走了兩顆」，拿走的變灰、打叉，數剩下的 |
| | 18 減法算式、19 減法小祕訣 | 減 0、減 1、全部拿走 |

| | 21 小故事 | 加減混在一起的小故事 |
| | 22 20 以內加法 | 十格盒先裝滿（9 + 3：先補一個變十），再往下數十一、十二 |
| F 乘法入門 | 23 幾個一盤 | 「有三盤，每盤兩顆」，一盤一盤跳著數（二、四、六） |
| | 24 跳著數 | 袋鼠火車：2、5、10 個一數，下一個是幾、少了哪個 |
| | 25 乘法算式 | 盤子圖＋算式 2 × 3（每盤 2 顆、3 盤；台灣課本的寫法） |
| G 除法入門 | 26 平分 | 點一下東西就分給下一隻小熊；問每隻小熊有幾顆 |
| | 27 除法算式 | 同上，加上算式 6 ÷ 2 |

- 為了少錄一點音，加減乘除的題目只用「顆」和「隻」的東西；乘除只用食物（蘋果、草莓、糖果）
- 錄音：edge-tts 有時會擋太頻繁的請求，`tools/record.py` 會等一等再重試（`TTS_JOBS` 可以調同時錄幾句）

## 第 5 段：更多數數、10 以內的玩法（47–64）
先教再考：每一課的前兩輪，第一題由小白先示範（「先看小白做一次」，照答錯時的示範一步一步做，再請孩子點發亮的答案），然後說「換你了！」才開始算分。舊的 46 課也一樣。

| 單元 | 新課 |
|---|---|
| 數與量 | 47 拿拿看（小白說幾個就拿幾個放進籃子，按「好了」；太多會拿回來）、48 數字比大小（數字下面有小圓點）、49 第幾個（從旗子這邊數，點那隻動物）、50 倒著數（火箭倒數小火車）、51 聽聽有幾下（小白敲鼓，用耳朵數；🥁 可以再聽一次） |
| 形狀、規律、時鐘（新） | 52 認識形狀（圓形、三角形、正方形、長方形：找形狀、數有幾個；答完說特徵）、53 找規律（AB、AAB、ABB、ABC：下一個是什麼、少了哪一個）、54 認識時鐘（整點：看時鐘說幾點、點鐘面上的數字把短針撥過去） |
| 分與合 | 55 變一樣多（按＋／−把下面放到和上面一樣多）、56 分合圖 |
| 加法 | 57 接著數（盒子上寫著幾個，不用再數，接著往下數）、58 骰子加法 |
| 減法 | 61 減幾才會變（7 − ? = 4，答錯時一個一個拿走） |
| 加減一起 | 59 算對了嗎（孩子當老師：⭕／❌）、60 哪個算式（看圖找算式） |
| 二位數 | 62 十和幾（10 + 3、十三是十和幾）、63 百數表（少了哪一個；前三題只看三排）、64 二位數比大小（先比十位，再比個位） |

首頁的單元字母照順序排（形狀、規律、時鐘排在數與量後面）；資料裡的單元代號不變。

## 🎮 小遊戲（首頁最上面）
每款都可以在上方切換程度（數數／加法／減法／加減，或湊五／湊十），切了就重新開始；沒有計時，一輪玩完送貼紙。
| 遊戲 | 玩法 |
|---|---|
| 🐶 餵動物 | 小狗、小兔子、小猴子的想法泡泡裡是數字或算式（3 + 2）。點食物餵牠，每餵一個念一個數字，餵好了按「吃飽了」。不夠會說「再餵一點」，太多會把多的還回來 |
| 🎈 戳氣球 | 上面是一盤東西（數數）或算式，五顆寫著數字的氣球慢慢飄上來，戳破對的那顆。答錯會念出點到的數字，對的氣球停下來發亮 |
| 🐠 魚缸 | 「有三條小魚，又游來了兩條」：小魚從旁邊游進來或游走，問現在有幾條。答錯時魚停下來一條一條數 |
| 🃏 湊數配對 | 8 張數字卡（下面有圓點），點兩張加起來是 5 或 10 的就消掉；配錯會念出加起來是多少。一輪 3 盤 |

- 程式在 `games.js`（用 index.html 的共用元件）；家長區也會列出小遊戲玩了幾輪
