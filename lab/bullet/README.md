# 星塵彈幕（`lab/bullet/`）

縱向捲軸彈幕射擊。三關（粉紅星雲邊境、冰晶小行星帶、黑洞核心），每關最後一隻魔王（鋼鐵巨蟹、三頭冰龍艦、日蝕），血量掉到一定程度會換招式。戰機自動開火，玩家只要閃子彈；只有機身中間的白點被打到才算中彈，擦過子彈（擦彈）加分。打倒敵人掉 ⭐ 分數、🔴 火力（最多 4 級）、🟢 炸彈。另外有「🎆 彈幕展示」：無敵、魔王一直灑慢慢飛的子彈，畫面上會累積到一萬顆左右，右上角顯示目前子彈數。
three.js **0.187.0** WebGPURenderer（沒有 WebGPU 自動退回 WebGL2）。

## 子彈公式（`bullets.js`，shader 和 CPU 一模一樣）
- 發射器：`v0` 起點與起點速度（敵人邊走邊射）、`v1` 開始／結束時間、間隔、一次幾顆（ring）、`v2` 第一發角度、每發轉多少（spin）、扇形間隔（0 = 平均一整圈）、速度、`v3` 加速度（負的＝減速到 4 成就固定）、轉彎（curve）、顏色＋10×大小、被炸彈消掉的時間。
- 第 k 顆：第 s = ⌊k / ring⌋ 發、這一發的第 m 顆；發射時間 tf = t0 + s × interval；角度 = a0 + s × spin + m × 間隔 + curve × 年齡 / 2；距離 = 速度 × 年齡 + ½ 加速度 × 年齡²。
- 炸彈、魔王換招：把 `cancel` 設成現在時間 → 之前射的子彈全部消失（之後再射的照常）；消失的子彈變成會自己飛過來的小星星。
- 招式（`stages.js` 的 `pat`）：aim（瞄準扇形）、ring（一整圈）、spiral（灑水器）、flower（會轉彎的花瓣）、rain（往下一排）。難度改速度和密度（一圈幾顆）。

## 坑（TSL）
- **整數除法**：`int(instanceIndex).div(512)` 會被當浮點數，不會捨去 → 用 `floor(float(instanceIndex).div(512))` 再 `int()` 當陣列索引。
- **頂點算的值要給像素 shader 用**：要用 `varyingProperty()`，`toVar()` 只在頂點 shader 裡有效（顏色會變 0、整個看不到）。
- **平面 xy 對應到世界 xz**：正反面會反過來被剔除 → 材質要 `DoubleSide`。
- 子彈很多時加法混色會整片白：`bullets.gain` 在展示模式調暗。
- WebGL 相容模式的頂點 uniform 上限大約 256 個 vec4，所以發射器只開 48 個。

## 存檔
`localStorage['mwLabBullet.v1']` = `{ best: { <難度 0–2>: 最高分 }, cleared: 已過幾關（解鎖選關）, diff, soundOff }`

## 操作
- 鍵盤：方向鍵／WASD 移動、Shift 慢速、X／空白鍵／K 炸彈、Esc／P 暫停。
- 觸控：手指在任何地方拖曳，戰機照手指移動的距離走（不會被手指擋住）；兩根手指＝慢速；右下 💣。

## 測試
- `?q=low|high`、`?gl=1`、`?offscreen=1&paused=1`、`?god`（無敵）。
- `window.__bh`：`start(關卡, 難度)`、`show()`、`boss()`（跳到魔王）、`sim(秒)`、`snap(秒)`、`G`、`bullets`。
- 自動玩（無敵、玩家跟著敵人的 x）跑完三關約 5 分鐘遊戲時間；展示模式穩定在 9000～10000 顆子彈。
