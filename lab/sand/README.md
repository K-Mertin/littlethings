# 沙之實驗室（`lab/sand/`）

落沙沙盒：倒沙子、水、岩漿、油、種子，放火、畫牆和木頭。每一格都是一顆粒子，全部在顯示卡上照規則移動。
有「自由玩」和 6 個「關卡」。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 版面、樣式（頂列、工具列、關卡選單、結果視窗） |
| `js/shaders.js` | WGSL：`STAMP`（筆刷／水龍頭／排水孔）、`STEP`（物理）、`COUNT`（數格子判斷過關）、`DRAW`（畫面＋火光） |
| `js/gpu.js` | WebGPU 引擎（直接用 WebGPU API，沒有用 three.js） |
| `js/cpu.js` | 沒有 WebGPU 時的相容模式：同一套規則用 JavaScript 跑，格子比較少，畫在 2D canvas。**改規則時 `shaders.js` 和 `cpu.js` 兩邊都要改** |
| `js/mats.js` | 材料編號、工具列設定、`Builder`（用比例座標畫關卡：rect、line、disc、cup、house、tree） |
| `js/levels.js` | 6 個關卡＋自由玩開場場景 |
| `js/main.js` | 輸入、模式、關卡判定、星星、存檔、測試掛勾 |

## 物理
- 每格一個 `u32`：0–7 位元材料、8–15 顏色變化、16–23 壽命／能量、26 關卡鎖定（橡皮擦擦不掉）。
- **Margolus 鄰域**：每個執行緒管一個 2×2 區塊，每一格輪流換位移，所以不需要原子操作也不會互相覆蓋。區塊隨機左右鏡射，避免往同一邊偏。
- 密度：煙／蒸氣 −2、火 −1、空 0、油 1、水 2、岩漿 3、種子 4、沙 5；牆、木頭、植物、石頭不會動。
- 反應：岩漿＋水 → 石頭＋蒸氣；火或岩漿點燃木頭、植物、種子、油；火碰水變蒸氣；種子碰水發芽（能量 40），植物喝水多長 12；蒸氣冷了有機會變回水滴。
- 每畫面跑 4 次（WebGPU）／2 次（相容模式），固定 60 格／秒。

## 關卡
| # | id | 目標 | 工具 |
|---|---|---|---|
| 1 | cup | 水龍頭的水引進杯子（一半） | 石牆（有限）、橡皮擦 |
| 2 | box | 沙子繞過大石頭進箱子 | 石牆、橡皮擦 |
| 3 | garden | 花盆裡長滿植物 | 種子、水 |
| 4 | twin | 一個水龍頭裝滿兩個杯子 | 石牆、橡皮擦 |
| 5 | lava | 保護小木屋 35 秒 | 水、沙、石牆 |
| 6 | forest | 森林火災保護小木屋 40 秒 | 水、沙、橡皮擦（防火巷） |

星星：用石牆的關卡看用了多少（≤40% 三顆、≤70% 兩顆）；保護關卡看小屋剩多少（≥97%、≥92%）；花園看時間（<40 秒、<75 秒）。
所有關卡一開始都可以玩（不鎖關）。

## 存檔
`localStorage['mwLabSand.v1']` = `{ stars: { <關卡 id>: 1–3 }, tool, size }`

## 操作
滑鼠／手指拖曳倒材料；鍵盤 1–9 換工具、`[` `]` 筆刷大小、空白鍵暫停。

## 測試
- `?cpu=1` 強制相容模式；`?offscreen=1&paused=1` 無頭瀏覽器用（畫到貼圖再讀回）。
- `window.__sand`：`startLevel(i)`、`startFree()`、`paint(x0,y0,x1,y1,工具,大小)`（比例座標）、`run(秒)`、`snap()`、`census()`、`L`（關卡狀態）。
