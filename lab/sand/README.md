# 沙之實驗室（`lab/sand/`）

落沙沙盒：倒沙子、水、岩漿、油、種子、冰，放火、畫牆和木頭，放水龍頭和黑洞。每一格都是一顆粒子，全部在顯示卡上照規則移動。
有「自由玩」和 9 個「關卡」。有音效（WebAudio 合成）。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 版面、樣式（頂列、工具列、關卡選單、結果視窗） |
| `js/shaders.js` | WGSL：`STAMP`（筆刷／水龍頭／排水孔）、`STEP`（物理）、`COUNT`（數格子判斷過關）、`DRAW`（畫面＋火光） |
| `js/gpu.js` | WebGPU 引擎（直接用 WebGPU API，沒有用 three.js） |
| `js/cpu.js` | 沒有 WebGPU 時的相容模式：同一套規則用 JavaScript 跑，格子比較少，畫在 2D canvas。**改規則時 `shaders.js` 和 `cpu.js` 兩邊都要改** |
| `js/mats.js` | 材料編號、工具列設定、`Builder`（用比例座標畫關卡：rect、line、disc、cup、house、tree） |

| `js/main.js` | 輸入、模式、關卡判定、星星、存檔、第一次的提示、過關彩紙、測試掛勾 |

## 畫面
- `DRAW` shader 在每個畫面像素算它在格子裡的位置：沙、種子、石頭做成一粒一粒；磚牆每塊磚有自己的亮暗和灰縫；水依深度變藍、表面亮、半透明；岩漿有流動的硬殼；油表面有彩虹光；花有五種顏色。
- 立體光影：把「實心格子」（不含液體、氣體）當成高度圖，用 Sobel 算表面法線，光從左上方照 → 沙堆、牆、木頭、石頭的邊緣是圓滑的斜面，朝光亮、背光暗，還有一點反光；材質自己也有小凹凸（磚縫凹下去、木紋起伏、每粒沙鼓鼓的）。被埋越深越暗，空格子在東西右下方有淡淡的影子。
- 火、岩漿、餘燼照亮附近（4 圈 × 8 方向取樣）。背景是黃昏天空、星星、兩層遠山。
- CPU 相容模式只有基本顏色（沒有這些效果）。

## 物理
- 每格一個 `u32`：0–7 位元材料、8–15 顏色變化、16–23 壽命／能量、26 關卡鎖定（橡皮擦擦不掉）。
- **Margolus 鄰域**：每個執行緒管一個 2×2 區塊，每一格輪流換位移，所以不需要原子操作也不會互相覆蓋。區塊隨機左右鏡射，避免往同一邊偏。
- 密度：煙／蒸氣 −2、火 −1、空 0、油 1、水 2、岩漿 3、種子 4、沙 5；牆、木頭、植物、石頭不會動。
- 新材料：冰（14，碰到火／岩漿融化；火的工具直接點在冰上也會融化）、花（15，植物長高後偶爾開花）、水龍頭（16，一直往下出水）、黑洞（17，吃掉旁邊會動的東西）。
- 冷熱（用每格的 life 位元組）：
  - 冰的 life 是「冷度」（40）。凍住一格水要分一半冷度給新的冰（冷度 ≥ 12 才凍得了）；被水碰著會一點一點變暖，冷度 0 再碰水就融化；冰和冰之間冷度會平均。→ 一大塊冰＋少少的水會凍住，一小塊冰丟進一大池水會融掉。
  - 岩漿的 life 是「熱度」（200）。碰到水 → 那格變石頭（冷度 60）＋蒸氣；碰到冰熱度 −50；碰到有冷度的石頭，石頭分一半冷度出去、岩漿熱度減三倍那麼多，熱度用完就變成石頭（帶著剩下的冷度，繼續往裡面傳）；岩漿和岩漿之間熱度會平均。熱度低的岩漿顏色變暗紅、發光變弱。
  - 石頭被水碰到會回到冷度 60（冰 80），石頭和石頭之間冷度會往下傳。→ 一直倒水或冰，整池岩漿會從外往內慢慢凝固。
  - `Builder.put()`（關卡）也會給冰、岩漿一樣的初始冷度、熱度。
- 反應：岩漿＋水 → 石頭＋蒸氣；火或岩漿點燃木頭、植物、種子、油；火碰水變蒸氣；種子碰水發芽（能量 40），植物喝水多長 12；蒸氣冷了有機會變回水滴。
- 每畫面跑 4 次（WebGPU）／2 次（相容模式），固定 60 格／秒。

## 關卡
| # | id | 目標 | 工具 |
|---|---|---|---|
| 1 | cup | 水龍頭的水引進杯子（一半） | 石牆（有限）、橡皮擦 |
| 2 | box | 沙子繞過大石頭進箱子 | 石牆、橡皮擦 |
| 3 | garden | 花盆裡長滿植物 | 種子、水 |
| 4 | twin | 一個水龍頭裝滿兩個杯子 | 石牆、橡皮擦 |
| 5 | lava | 保護小木屋 35 秒 | 水、沙、石牆 |
| 6 | forest | 森林火災保護小木屋 40 秒 | 水、沙、橡皮擦（防火巷） |
| 7 | melt | 用火融冰，水引進杯子 | 火、石牆、橡皮擦 |
| 8 | bloom | 花盆開出很多花 | 種子、水、水龍頭 |
| 9 | oilfire | 油槽著火，守住小屋 35 秒 | 水、沙 |

星星：用石牆的關卡看用了多少（≤40% 三顆、≤70% 兩顆）；保護關卡看小屋剩多少（≥97%、≥92%）；花園看時間（<40 秒、<75 秒）。
所有關卡一開始都可以玩（不鎖關）。

## 存檔
`localStorage['mwLabSand.v1']` = `{ stars: { <關卡 id>: 1–3 }, tool, size }`

## 操作
滑鼠／手指拖曳倒材料；鍵盤 1–9 換工具、`[` `]` 筆刷大小、空白鍵暫停。

## 測試
- `?cpu=1` 強制相容模式；`?offscreen=1&paused=1` 無頭瀏覽器用（畫到貼圖再讀回）。
- `window.__sand`：`startLevel(i)`、`startFree()`、`paint(x0,y0,x1,y1,工具,大小)`（比例座標）、`run(秒)`、`snap()`、`census()`、`L`（關卡狀態）。

## 逼真調整
- 沙：每粒顏色不同（淺黃／土黃，少數深色顆粒和黑色礦物），表面偶爾閃一下。
- 水：透明，看得到後面的背景（輕微折射晃動），越深吸收越多紅光、越偏藍綠，水裡有光紋，表面一條反光。
- 火光、岩漿光：往 12 個方向一格格追，牆、石頭、木頭、沙會擋光（有影子），水會讓光變弱（只有 WebGPU 版）。
- 煙、蒸氣：看周圍 5×5 格的密度畫成柔和的雲（空氣格也會畫淡淡的邊）。
