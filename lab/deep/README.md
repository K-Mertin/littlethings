# 深海探險隊（`lab/deep/`）

駕駛小潛水艇探索海底：珊瑚礁淺海 → 斜坡 → 很暗的深海和海溝。靠近生物就記進「海洋圖鑑」（17 種），順便撿 20 個垃圾；左上有 9 個依序解鎖的探險任務，R 鍵聲納會指向還沒找到的生物。
three.js **0.187.0** WebGPURenderer（沒有 WebGPU 自動退回 WebGL2）。

## 世界
- 座標：x 左右，z 往前越來越深（z −170 珊瑚礁 → z +170 海溝），海面 y = 0。邊界 ±148。
- 珊瑚礁中心 (−10, −112)、昆布森林 (−62, −78)、海葵 (6, −128)、章魚大石頭 (28, −95)、水母群 (26, 92)、鮟鱇魚 (−48, 118)、熱泉 (−18, 140)。
- 霧（`FogExp2`）和光都跟著**鏡頭深度**變：淺海藍綠、40 m 以下深藍、80 m 以下幾乎全黑。背景是一顆跟著鏡頭的大球，經過同樣的霧，所以遠方和霧色一致。
- 深海的水母、鮟鱇魚、管蟲要**開探照燈**才會記進圖鑑。

## 魚群（boids）
- 每群的魚放在緩衝區的連續一段，每條魚只看前後第 1、2、3、5、8 條鄰居（分開＋對齊），加上往魚群中心靠、離潛艇 9 m 內散開、一點亂游。
- 魚群中心在 CPU 上沿各自的路線晃，潛艇靠太近整群會躲開一陣子。
- 外形：流線型魚身（旋轉體：前段最厚、頭比較尖、尾柄細）＋分叉尾鰭、背鰭、臀鰭、胸鰭；shader 畫眼睛（黑點＋亮邊）、鰓蓋線、側線；每條魚大小差 ±17%。頂點 shader 依速度轉向、擺尾巴。

## 細節效果
- **光紋打在東西上**：`causticOn()`（world.js）讓珊瑚、石頭朝上的面也有晃動的水面光紋。
- 石頭有小坑、朝上長藻類、側面有粉紅色殼狀珊瑚藻；鏡頭預設拉遠一點（10.5 m），潛艇不會擋住畫面。
- **斯涅耳窗**：海面從下面看，只有頭頂約 97° 的圓看得到天空（亮、會晃），圓外是全反射（暗藍綠），邊緣一圈亮光（`cos(視線, 上) ≈ 0.66`）。
- **背景球**：往上越亮、往下越暗，水平剛好等於霧色（`W.fogU` 跟著 `scene.fog.color`）。
- **水的光吸收**（逼真的關鍵）：後製用深度算每個像素離鏡頭多遠，`顏色 × exp(-距離 × (0.075, 0.024, 0.01))`——紅色最先消失、藍色走最遠；潛得越深整體紅色也越少。距離上限 45 m（背景球不算）。
- 沙地有海流推出的沙紋和細顆粒；焦散光紋亮度調低；魚鱗加一點金屬光澤。
- **氣泡**：CPU 環狀緩衝 260 顆，每格上傳到 `instancedArray`；幾何本身就是小方塊（0.22），`positionNode` 只加位移——在 positionNode 裡縮放會讓 billboard 出錯（潛艇周圍出現白圈）。
- **探照燈光束**：加法混色的圓錐，亮度 ∝ `along*(1-along)`，只在開燈時顯示。
- **海扇**：用真的細枝幾何（`seaFanGeo`）分岔 7 層，不是平面貼花紋。
- 珊瑚長成一叢一叢（46 個叢集，80% 的珊瑚放在叢集附近），中間留沙地。

## 坑
- **InstancedMesh 加 `positionNode` 時，three 0.187 不會套用每棵的矩陣**（全部擠在原點）。昆布、海葵改成自己做 instancing：位置放在 `instancedArray`，`mesh.count = N`，在 positionNode 裡自己加位置（見 `world.js` 的 `sway()`）。
- `new THREE.FogExp2(color)` 會**複製**顏色，要改霧色得改 `scene.fog.color`。

## 存檔
`localStorage['mwLabDeep.v1']` = `{ found: [圖鑑 id…], trash: [垃圾編號…], light, soundOff, mission, maxDepth }`（`mission`、`maxDepth` 是新欄位，舊存檔沒有就從 0 開始）。圖鑑視窗有「重新開始探險」。

## 操作
- 鍵盤：W／S 前進後退、A／D 轉彎、空白鍵（或 E）上浮、Shift（或 Q、C）下潛、F 探照燈、R 聲納、B／Tab 圖鑑、滑鼠拖曳看四周、滾輪拉遠拉近。
- 觸控：左下搖桿、右下 ⬆️⬇️、拖曳畫面看四周。
