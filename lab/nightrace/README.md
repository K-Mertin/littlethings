# 夜雨賽車（`lab/nightrace/`）

下雨的城市夜賽 MW NIGHT GP：濕路映著霓虹和路燈、車燈照亮雨幕、車輪甩起水花，路上的水窪會讓車子打滑，大雨時會打雷閃電。
三條賽道（霓虹市區、港灣大道、環城高架）。和 5 台電腦車比賽、跑**錦標賽**（三條賽道連比三場，名次積分 10／8／6／4／3／2，最後積分最高的是總冠軍），或自己跑計時賽（有幽靈車陪跑）。比賽結束可以「開回大街」（連到 `/lab/street/`）。
three.js **0.187.0** WebGPURenderer（沒有 WebGPU 自動退回 WebGL2）。

## 物理
- 前後方向直接加速／煞車；側滑速度靠「抓地力」每格消掉一部分 → 自然會甩尾。
- 抓地力：基本 7.5 × (1 − 0.28 × 濕度) × (1 − 0.45 × 水窪)；手煞車 × 0.22。
- **水窪**是一張沿著賽道的小圖（1024 × 16），路面 shader 和物理讀同一份，所以看得到的水窪就是會滑的地方。
- 護欄：算車子離中心線多遠，超過就推回來、反彈、減速。
- 電腦：往前 0～90 m 每一段算「過彎速度＋來得及煞車」取最小值當目標速度，方向盤對準前方的點；落後太多會快一點、領先太多慢一點。

## 存檔
`localStorage['mwLabNight.v1']` = `{ best: 霓虹市區最快一圈秒數, bests: { harbor: … }, opts: { mode（race／cup／tt）, laps, diff, rain, color, track }, cupBest: 錦標賽最好名次, soundOff }`（`best` 沿用舊格式，新賽道放 `bests`）
幽靈車：`localStorage['mwLabNight.ghost.<賽道 id>']` = `{ t: 那圈秒數, p: [[x, z, 方向]…] }`（每 0.1 秒一筆）。比幽靈車快就換掉。

## 畫面小撇步
- 參考 ATI ToyShop 雨景（SIGGRAPH 2006〈Artist-Directable Real-Time Rain Rendering in City Environments〉）：
  - **路燈光錐**：加法混色的圓錐，裡面是往下捲動的噪聲（看得到雨絲落下），邊緣用 `|normalView · 視線|` 淡掉。
  - **濕路長條倒影**：每盞燈在路面拉一條朝向鏡頭的光帶（頂點 shader 依鏡頭方向擺），亮度 ∝ 濕度²。
  - **擋風玻璃雨滴**（車內視角）：後製用格子放雨滴、取樣後面的畫面做折射；雨刷每 2.4 秒掃一次，依角度算出每個像素上次被刷的時間，雨滴再隨機慢慢出現。
- 大樓一樓有一排亮著的店面櫥窗；高樓頂上有退縮的小樓、冷氣機、紅色航空警示燈。
- 泛光只吃 MRT 的自發光層，**不會被霧蓋掉** → 大樓窗戶的自發光要自己乘上 `exp(-距離 × 0.011)`，不然遠方天空會有一團團灰霧。
- 車燈光束用 `|normalView · 視線|` 讓邊緣淡掉，才不會出現硬邊三角形。

## 操作
↑／W 油門、↓／S 煞車倒車、←→／AD 轉彎、空白鍵 手煞車、R 回賽道、C 換視角（追車／車頭／車內）、Esc 暫停。觸控：左邊 ◀▶、右邊油門／煞車、↯ 手煞車。
