# 銀河建造師（`lab/galaxy/`）

兩種玩法：
- **星系沙盒**：幾十萬顆星被星系核心和黑洞的重力吸引。預設場景：旋臂星系、兩個星系相撞、大星系吃小星系、黑洞闖進來、星雲漩渦；也可以自己放星系／黑洞（按住拖一下決定速度）。
- **軌道任務**：5 個彈弓發射關卡（繞太陽一圈、月亮繞行星、彗星進太陽系、彈弓加速、雙星系統），學萬有引力和軌道。
- **天文小百科**：12 張卡片，任務成功時也會跳出對應的那張。

three.js **0.187.0** WebGPURenderer（沒有 WebGPU 自動退回 WebGL2）。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 版面：頂列、下方工具列、任務 HUD、任務選單、結果視窗、小百科 |
| `js/main.js` | 渲染器與後製（泛光、拖尾 `afterImage`）、模式切換、指標（轉視角、放東西、彈弓）、鏡頭、主迴圈、背景星空、測試掛勾 |
| `js/stars.js` | 星星 GPU 系統：`spawnNode`（在某一段緩衝區生出旋臂星系／星雲，或清掉）、`stepNode`（受重天體吸引、被黑洞吃掉）、畫法；重天體（核心、黑洞）在 CPU 做完整 N-body |
| `js/orbits.js` | 軌道任務：CPU 小模擬（每格 8 個子步）、預測線、拖尾線、彗星尾巴、天體標籤 |
| `js/data.js` | 預設場景、任務（天體、發射限制、勝負判定 `check`）、小百科內容 |

## 星系模擬（受限 N 體）
- 星星**彼此不吸引**（那要 N² 次），只受最多 16 個重天體的 Plummer 位能吸引：`a = M·d / (|d|² + ε²)^1.5`。星系核心的 ε 是半徑的 0.12（自轉曲線比較平），黑洞 ε 很小、而且有「吃掉半徑」。
- 這就是 Toomre 兄弟 1972 年解釋觸鬚星系潮汐尾巴的方法。
- 星星緩衝區分成 4 格（slot），每個星系佔 1～4 格；滿了會回收最舊的星系。生成在 GPU 上做（不用從 CPU 重傳整個緩衝區）。
- 數量：WebGPU 高畫質 24 萬、低畫質 9 萬、相容模式 2.4 萬（`?n=` 可以指定）。星星越多每顆越暗（`kN`），不然中間會疊成一團白。

## 任務單位
G 併進 `gm`（太陽 400）。時間：模擬秒 = 真實秒 × 3 × 速度。發射速度 = 拉的距離 × 0.32，上限看任務。
勝負條件在 `data.js` 每個任務的 `check(st)`；`st` 有位置、速度、時間、繞了幾圈（`sweep`、相對某天體 `sweepRel`）、最近距離 `minR`。
5 個任務都用暴力搜尋確認過有解（`__gal.tryLaunch` 掃 216 種發射方向和速度）。

## 存檔
`localStorage['mwLabGalaxy.v1']` = `{ stars: { <任務 id>: 1–3 }, speed, trails }`。星星：第 1 次就成功 3 顆、3 次內 2 顆。

## 操作
- 星系沙盒：拖曳轉視角（「放星系／黑洞」工具時用右鍵）、滾輪或兩指縮放、空白鍵暫停、1–5 換預設場景。
- 軌道任務：在要發射的東西上按住、往後拉、放開；R 重來。
