# 萬軍對決 3D（`lab/army/`）

「萬軍守城」的大軍對決搬到 3D 戰場：劍盾兵、弓箭手、騎兵，兩邊加起來最多約 3000 人（WebGPU 高畫質）。
6 場戰役＋自由對戰。玩家是藍軍：選隊伍 → 點地面走過去，或拖一條線讓隊伍沿線排開；「衝鋒」「停下」。
three.js **0.187.0** WebGPURenderer（沒有 WebGPU 自動退回 WebGL2）。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 版面：頂列（兩軍人數條、速度、暫停、選單、聲音）、戰役說明、下方按鈕、小地圖、選單（戰役＋自由對戰設定）、結果 |
| `js/main.js` | 渲染器、鏡頭（拖曳平移、右鍵／兩指旋轉縮放、WASD）、每隊的軍旗（隨風飄）＋血條、小地圖（點一下移鏡頭）、選隊伍與下命令、佈陣、勝負、存檔、測試掛勾 |
| `js/sim.js` | **戰鬥模擬（CPU）**：typed array＋空間格子（2 m 一格）；找最近敵人、移動、互相閃開、近戰、弓箭拋物線、電腦 AI（hold／wait／advance／flank） |
| `js/units.js` | **士兵外形與動畫（GPU）**：程式拼的低多邊形人和馬；每個頂點記住部位和轉軸，頂點 shader 依「跑步相位、攻擊、倒下」轉手腳；每種兵一次 draw call；有披風（part 7，跑起來往後飄）、肩甲、箭袋、馬衣等細節；箭也是 instancing |
| `js/terrain.js` | 地形：山丘、河流（淺灘、橋）、樹林、草叢和小花（自己做 instancing、隨風擺）、石頭、天空、遠山、雲、地圖外的草原；`height()`、`speedAt()` 給模擬用 |
| `js/dust.js` | 塵土粒子：跑步（騎兵最多）揚起的土、倒下時的一團灰；CPU 粒子池，自己做面向鏡頭（每顆大小不同） |
| `js/battles.js` | 6 場戰役與自由對戰的部隊配置 |
| `js/audio.js` | WebAudio 合成：戰鼓、刀劍、箭雨、號角 |

## 規則（數值在 `sim.js` 的 `STATS`）
| 兵種 | 血 | 傷害 | 速度 | 特別 |
|---|---|---|---|---|
| 劍盾兵 | 100 | 11 | 3.2 | 盾牌：箭傷害 ×0.5 |
| 弓箭手 | 70 | 6（近戰） | 3.0 | 射程 34（站高處 ×1.25），每 3.2 秒一箭 15 傷害 |
| 騎兵 | 200 | 18 | 7.2 | 衝鋒第一下 ×2.5（之後要 5 秒才能再衝） |
- 河裡速度 ×0.45（淺灘、橋不受影響）；樹林速度 ×0.7、箭傷害 ×0.5。
- 勝負：一方剩不到 8%。星星：藍軍剩 ≥60% 三顆、≥35% 兩顆。
- 玩家的移動命令（`orderSquad(..., move=true)`）走到之前不會停下來打（除非敵人貼身）。

## 平衡
用 `/tmp` 下的 node 腳本跑過所有戰役（無畫面，1 步 ≈ 0.4～2.4 ms）：第 1～3 關直接衝或原地守都能贏；第 4 關（騎兵包抄）要讓騎兵繞去打弓箭手；第 5 關（森林）要弓箭手進樹林、劍盾兵直接去打弓箭手；第 6 關大決戰衝鋒會贏但損失大。
改數值後建議照 README 這段再跑一次（`Battle` 不依賴 three.js，可以直接在 node 裡用；`terrain.js` 只要去掉 `build()`）。

## 逼真調整
- 士兵的手腳、靴子改成膠囊、上衣是上寬下窄的圓柱，有脖子和手掌。
- 每個人腳下有接觸陰影（淡黑圓，騎兵是長的，跟著方向轉），WebGPU 低畫質也開太陽影子。
- 隊伍顏色改成布料染色的藍和紅；陽光偏暖、角度斜一點。

## 坑
- 頂點屬性 `kind`、`part` 是浮點數，插值後可能變成 4.9999…，直接 `equal()` 會讓顏色一點一點跳錯（像雜訊）。先 `.add(0.5).floor()` 再比較。
- `billboarding()` 用的是幾何本身的大小；要每顆粒子大小不同就自己用鏡頭的 right／up 向量算（見 `dust.js`）。
- 霧的 near／far 跟著鏡頭距離調，拉遠時才不會整片白。
