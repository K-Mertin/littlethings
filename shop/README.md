# 夜市小吃王 · Night Market Tycoon

從一台小攤車開始，把它經營成夜市排行榜第一名的美食大街！像素小人的模擬經營遊戲，所有圖案和音樂都是程式即時畫出、合成的，不需要任何圖檔或音檔。

自己的店是畫面的主角：每一級都有自己的店面（鐵皮小攤 → 瓦片屋簷 → 二樓窗台 → 紅磚 → 金邊 → 琉璃瓦），鄰居那邊會比較暗、比較灰。夜市街景有兩層樓的街屋、直式招牌、隔壁攤販、騎樓地磚、路燈、斑馬線、對面一排帳篷，傍晚到深夜會慢慢變暗、燈光亮起；下雨、颱風、寒流、春天花瓣、秋天落葉、夏天螢火蟲、春節和跨年的煙火都會出現在畫面上。

## 怎麼玩

- **建造**：在店面格子上擺攤位、桌椅、裝飾、遊戲攤和地板。某些東西放在隔壁（斜的也算）會觸發「擺設組合」，有加成效果，一共 34 種等你發現。
- **員工**：每個月會有新的應徵者。員工有廚藝、服務、魅力三種能力，可以培訓、會升級。工作分成廚師（顧攤位）、外場（清桌子、招呼排隊客人）、攬客（站在門口拉客人）。
- **菜單**：調整每道菜的價錢、上架或休息、用靈感改良菜色（最高 Lv10）。跟批發商簽約，解鎖新的食材。
- **研發**：把兩樣食材（或已研發的菜）組合起來，研發新菜色。一共 54 道菜（最後一道是「夜市滿漢全席」），食譜筆記裡有猜謎提示和每道菜賣出的份數。
- **事業**：
  - 委託：附近的人會來拜託你（想吃某道菜、招待某種客人、賣出某類菜、口碑調查、想看某種裝飾），完成有獎勵。
  - 節慶限定挑戰：春節、端午、暑假、中秋、跨年等月份會有限定目標。
  - 活動：花錢舉辦試吃大會、街頭演唱會、花車遊行、煙火晚會、夜市美食節。
  - 秘方：用靈感和錢研究 8 種永久加成（最高 5 級）。
  - 分店：美食廣場以後可以到士林、饒河、逢甲、六合、羅東、東京開分店並升級。
- **經營**：排行榜、目標、成就、組合圖鑑、客人圖鑑、評論、每月報表。
- **員工特質**：快手、大嗓門、愛乾淨、笑容可掬、鐵人、好學、慢郎中，還有稀有的天才廚師、明星架勢。

- **季節限定菜色**：草莓糖葫蘆、芝麻湯圓、櫻花雪花冰、冰鹼粽、西瓜牛奶、蛋黃酥、糖炒栗子、薑母鴨、熱豆漿，到了那個月份會自動上架，客人特別想吃（食譜筆記另有一區）。
- **對手的挑戰書**：排行榜上跟你最近的店會來下戰帖（兩週內的客人數、營業額或某類菜的份數），先付賭注；贏了賭注加倍拿回、人氣上升、對手人氣下滑一陣子，輸了就賠掉。
- **年度故事**：每年年初阿德伯會說一段故事，並給一個「年度目標」，年底檢查，達成有獎勵。
- **分店巡視**：每家分店都有自己的風景（士林大牌樓、饒河廟口、逢甲霓虹、六合椰子樹和高塔、羅東公園水池、東京紅白鐵塔），等級越高攤位和人潮越多。
- **吃東西的瞬間**：桌上會有那道菜的小盤子（慢慢吃光、熱的冒煙），喝飲料會拿起杯子；吃到一半會有反應（辣的頭上冒火、冰的說透心涼、季節限定會特別開心）。每種攤位煮東西的動畫都不一樣（翻餅、油泡泡、搖雪克杯、湯杓攪拌、蒸籠蓋被頂起來、炭火跳動、刨冰機轉）。員工升級會跳起來、撒彩紙，右下角有升級卡片。

## 時間與目標

- 遊戲裡有年、月、週，每個月有節慶（春節、暑假、中秋…），每週可能發生事件（颱風、美食節目、網紅來訪、衛生稽查…）。
- 每年 10 月有「夜市小吃大賽」，年底有頒獎典禮，依排行榜名次拿獎金和獎盃裝飾。
- 人氣夠、錢夠就能擴建：路邊小攤 → 巷口小吃店 → 排隊名店 → 美食廣場 → 夜市大街 → 傳說夜市。
- 拿下夜市之王（或經營滿十年）會看到結局，之後可以繼續經營：攤位可以升到 5 級（金色攤車）、開分店、辦煙火晚會。
- **新手教學**：新遊戲會由隔壁的阿德伯一步一步帶你（擺桌椅、研發、調價、請人、擺設組合），可以跳過，也能在選單重看。
- **傳承**：經營滿 5 年或看到結局後，可以把店傳給下一代，得到「傳承點數」。成就第一次解鎖也會給點數。點數在標題畫面換開局加成（資金、秘方、老主顧、靈感、老師傅），所有存檔共用。
- **遊戲模式**：標準模式、甜點專賣店（只賣甜的和喝的）、素食小館（不用肉和海鮮），以及通關後解鎖的限時挑戰（5 年內拿第一）、逆境開局（本金少、租金兩倍）和觀光夜市（觀光客三倍、租金貴五成）。

## 操作

- 滑鼠或手指：點按鈕、點格子放置；拖曳移動畫面；滾輪或雙指縮放。
- 點攤位、桌子、裝飾可以升級、移動或賣掉；點員工可以換工作。
- 鍵盤：空白鍵暫停/繼續，1～3 調速度，0 暫停，Esc 關閉視窗。
- 右上角可以切換暫停 / 1 倍 / 2 倍 / 4 倍速度，以及開關聲音。

## 存檔

三個存檔欄位，存在瀏覽器的 localStorage。新系統的欄位（年度目標、挑戰書、對手人氣下滑）都是選填，舊存檔直接讀得進來。每個月底、每分鐘、切到背景時都會自動存檔。舊版（v1）存檔會自動轉換成新格式（員工補上特質、教學視為已完成）。成就和傳承點數另外存在 `shop.legacy`。

## 檔案

```
shop/
  index.html     頁面、樣式、HUD
  js/util.js     共用工具、設定
  js/data.js     設施、食材、菜色、組合、顧客、對手、目標資料
  js/audio.js    WebAudio 音效與音樂合成
  js/art.js      像素圖（人物走路／動作／表情、大頭像、攤車、設施、地板、圖示）
  js/sim.js      經營模擬（地圖、尋路、排隊動線、人群避讓、客人、員工、經濟、日曆、事件、委託、分店、活動、秘方、成就）
  js/meta.js     跨存檔的傳承（成就、點數、開局加成）與新手教學
  js/render.js   畫面（快取街景、夜晚燈光圖層、天氣、煙火、影子、特效）
  js/ui.js       面板、彈出視窗、提示
  js/bot.js      自動玩家（測試／平衡用）：照藍圖整齊擺設（攤位一排、桌椅成列、裝飾湊組合），按優先順序花錢
  js/main.js     主迴圈、輸入、存檔、標題畫面
```

測試用的除錯介面：`window.__shop`（例如 `__shop.run(48, true)` 會用自動玩家快轉一年；自動玩家也會接委託和挑戰書、研究秘方、辦活動、開分店，每種模式都玩得下去）。

## 效能

- 人物、設施、文字都會快取成小圖；文字（招牌、金額、對話）依縮放畫成貼圖，不用每格 `fillText`。描邊用畫的時候記下的遮罩算，不讀回像素。
- 不會動的燈（鄰居、路燈、帳篷、店裡燈泡串）合成一張低解析度燈光圖，每格只貼一次；物件排序用物件池，每格不產生新物件。
- 人群互推用數字格子、每兩步算一次；每格最多跑 6 步模擬，慢的手機會讓時間變慢而不是越來越卡。
- 畫質：自動（預設）／高／中／省電。自動模式連續 4 秒平均每格超過 26ms 會降一級（降解析度、關光暈層、少粒子），可在「選單」調整。

畫面分成四層 canvas：`#cv` 世界（天空漸層用 CSS 背景）、`#lt` 低解析度的夜晚暗色遮罩（燈光挖洞）、`#bl` 光暈（`mix-blend-mode: screen`）、`#fxc` 最上層的特效和泡泡。縮放和混色交給瀏覽器合成，手機上比較省電。
