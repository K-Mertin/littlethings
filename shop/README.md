# 夜市小吃王 · Night Market Tycoon

從一台小攤車開始，把它經營成夜市排行榜第一名的美食大街！像素小人的模擬經營遊戲，所有圖案和音樂都是程式即時畫出、合成的，不需要任何圖檔或音檔。

自己的店是畫面的主角：每一級都有自己的店面（鐵皮小攤 → 瓦片屋簷 → 二樓窗台 → 紅磚 → 金邊 → 琉璃瓦），鄰居那邊會比較暗、比較灰。夜市街景有兩層樓的街屋、直式招牌、隔壁攤販、騎樓地磚、路燈、斑馬線、對面一排帳篷，傍晚到深夜會慢慢變暗、燈光亮起；下雨、颱風、寒流、春天花瓣、秋天落葉、夏天螢火蟲、春節和跨年的煙火都會出現在畫面上。

## 新手引導

第一次玩不用怕，會有人一步一步帶：

- **開場故事**：五幕像素插圖＋對話——夜市的燈亮了、阿嬤留下的老攤車和食譜筆記、隔壁賣香腸的阿德伯、夜市排行榜（你排倒數）、開張！可以跳過，新遊戲只播一次（「選單」可以重看）。
- **阿德伯的十堂課**：一開始時間是暫停的，只有阿嬤的鐵板煎台和老闆自己，畫面上只看得到日期、錢和速度。之後依序：按 x1 開門賣出 8 份 → 擺好阿德伯送的飲料吧（阿珠加入）→ 擺桌椅 → 調價錢 → 研發 → 請人 → 擺設組合 → 人氣與排行榜 → 擴建成巷口小吃店 → 出師。每一課開始時阿德伯會說明（說話時時間停住），該按的按鈕會發亮、店裡會標出「放這裡」的格子，新打開的按鈕有「新」字，完成有小獎勵。還沒教到的按鈕、分頁、數值都先藏起來。
- **目前目標**：左上角的小卡片一直顯示現在要做什麼和進度，點一下可以再聽一次說明，「?」打開說明頁，「–」縮小。引導結束以後會改成「下一步」：委託進度、下一次擴建還差多少、今年的目標、下一個目標。
- **阿德伯的提示**：卡住的時候會跳出來——時間停著、菜單沒菜、攤位沒廚師、排隊太長、桌子太髒、座位不夠、價錢太貴、月底錢不夠付薪水、客人太少、靈感存太多、可以擴建了。可以按「怎麼做？」看說明，也能在「選單」關掉。
- **怎麼玩**：有圖的說明頁（基本流程、時間與金錢、建造、座位、菜單與價錢、研發、員工、擺設組合、人氣與擴建、事業、一年的行事曆），標題畫面和「選單」都能打開。
- 標題畫面有「新手引導 開／關」。舊存檔、傳承的下一代都直接跳過引導；在前幾課就跳過的話，會補上一般開局的飲料吧、阿珠和桌椅。

## 怎麼玩

- **建造**：在店面格子上擺攤位、桌椅、裝飾、遊戲攤和地板。某些東西放在隔壁（斜的也算）會觸發「擺設組合」，有加成效果，一共 42 種等你發現。
- **員工**：每個月會有新的應徵者。員工有廚藝、服務、魅力三種能力，可以培訓、會升級。工作分成廚師（顧攤位）、外場（清桌子、招呼排隊客人）、攬客（站在門口拉客人）。
- **菜單**：調整每道菜的價錢、上架或休息、用靈感改良菜色（最高 Lv10）。跟批發商簽約，解鎖新的食材。
- **研發**：把兩樣食材（或已研發的菜）組合起來，研發新菜色。一共 67 道菜（最後一道是「夜市滿漢全席」），食譜筆記裡有猜謎提示和每道菜賣出的份數。擴建成「夜市大街」後，菜可以改良成傳說級（最高 Lv15）。
- **快炒台**（排隊名店解鎖）：大火一甩、火花亂竄的新攤位，配上新食材蒜頭、蛤蜊、鮮魚、麻油、鳳梨，有塔香炒蛤蜊、三杯雞、宮保雞丁、鳳梨蝦球、海港大拼盤等 13 道新菜。
- **機能設施**：大冰箱（食材成本 -5%）、外帶窗口（外帶客人比較開心）、員工休息室（體力 +20、累了恢復較快），還有漁網浮球、山櫻花樹、廟會大鼓、燈塔模型等新裝飾和 8 個新組合。
- **事業**：
  - 委託：附近的人會來拜託你（想吃某道菜、招待某種客人、賣出某類菜、口碑調查、想看某種裝飾），完成有獎勵。
  - 節慶限定挑戰：春節、端午、暑假、中秋、跨年等月份會有限定目標。
  - 活動：花錢舉辦試吃大會、街頭演唱會、花車遊行、煙火晚會、夜市美食節。
  - 秘方：用靈感和錢研究 8 種永久加成（最高 5 級）。
  - 分店：美食廣場以後可以到士林、饒河、逢甲、六合、羅東、東京、曼谷、新加坡、紐約開分店並升級。
- **經營**：排行榜、目標、成就、組合圖鑑、客人圖鑑、評論、每月報表。
- **員工之間**：一起工作久了會變成好搭檔（同時上班動作快 10%）；兩個人較勁時可以讓他們比兩週（贏的能力 +3，說不定還會變搭檔）；每月可能有進修班（派一個人上課一週，能力大幅提升）；員工太強會被對手挖角，要加薪留人還是收轉職費由你決定。第一次發生時阿德伯會說明。
- **員工特質**：快手、大嗓門、愛乾淨、笑容可掬、鐵人、好學、慢郎中，還有稀有的天才廚師、明星架勢。

- **季節限定菜色**：草莓糖葫蘆、芝麻湯圓、櫻花雪花冰、冰鹼粽、西瓜牛奶、蛋黃酥、糖炒栗子、薑母鴨、熱豆漿，到了那個月份會自動上架，客人特別想吃（食譜筆記另有一區）。
- **對手的挑戰書**：排行榜上跟你最近的店會來下戰帖（兩週內的客人數、營業額或某類菜的份數），先付賭注；贏了賭注加倍拿回、人氣上升、對手人氣下滑一陣子，輸了就賠掉。
- **年度故事**：每年年初阿德伯會說一段故事，並給一個「年度目標」，年底檢查，達成有獎勵。
- **分店巡視**：每家分店都有自己的風景（士林大牌樓、饒河廟口、逢甲霓虹、六合椰子樹和高塔、羅東公園水池、東京紅白鐵塔），等級越高攤位和人潮越多。
- **吃東西的瞬間**：桌上會有那道菜的小盤子（慢慢吃光、熱的冒煙），喝飲料會拿起杯子；吃到一半會有反應（辣的頭上冒火、冰的說透心涼、季節限定會特別開心）。每種攤位煮東西的動畫都不一樣（翻餅、油泡泡、搖雪克杯、湯杓攪拌、蒸籠蓋被頂起來、炭火跳動、刨冰機轉）。員工升級會跳起來、撒彩紙，右下角有升級卡片。

## 挑戰關卡與地點

新手引導結束、店擴建過一次以後，阿德伯會介紹「挑戰關卡」（標題畫面）。12 個關卡分在四個地點，每關有期限（1～5 年）和三個目標：第一個目標達成就過關（★），三個都達成是 ★★★。新拿到的星星每顆換 1 點傳承點數；挑戰關卡不套用傳承加成。

- **老街夜市**：阿嬤的味道、甜點女王（甜點專賣店）、一年翻身（逆境開局）。
- **海港夜市**：海鮮食材便宜四成、海鮮菜特別受歡迎，有「漁夫」客人和「漁船進港」事件；夏天颱風多。背景是海、燈塔（光束會轉）和漁船，對面是木棧道和停泊的漁船。關卡：漁港的第一盞燈、颱風季、海港之王。
- **山城老街**：租金便宜三成、人比較少、登山客出手大方，熱湯和蒸籠好賣，寒流多；有「登山團下山」事件。背景是山脊、寶塔和會動的纜車。關卡：山上的小攤、寒冬熱湯、觀光老街。
- **廟會嘉年華**：人潮 1.25 倍但租金貴六成，進香團和「神明遶境」事件，廟口裝飾（小廟、燈籠、石獅、大鼓）魅力加倍。背景是大廟和摩天輪。關卡：廟口開張、遶境大拜拜、嘉年華霸主。

某個地點的關卡拿到星星後，一般遊戲也能在那個地點開店（標題畫面「地點」）。進行中的關卡會在左上角顯示三個目標和剩下幾週，結束時有星星結算。

## 時間與目標

- 遊戲裡有年、月、週，每個月有節慶（春節、暑假、中秋…），每週可能發生事件（颱風、美食節目、網紅來訪、衛生稽查…）。
- 每年 10 月有「夜市小吃大賽」，年底有頒獎典禮，依排行榜名次拿獎金和獎盃裝飾。
- 人氣夠、錢夠就能擴建：路邊小攤 → 巷口小吃店 → 排隊名店 → 美食廣場 → 夜市大街 → 傳說夜市。
- 擴建成美食廣場以後，每年 6 月有「夜市美食指南」評鑑，最多三顆星（每顆星每週人氣 +4、客人多付 4%），標準一年比一年要維持，星星會掉。
- 拿下夜市之王（或經營滿十年）會看到結局，之後可以繼續經營：攤位可以升到 5 級（金色攤車）、開分店、辦煙火晚會。
- **傳承**：經營滿 5 年或看到結局後，可以把店傳給下一代，得到「傳承點數」。成就第一次解鎖也會給點數。點數在標題畫面換開局加成（資金、秘方、老主顧、靈感、老師傅），所有存檔共用。
- **遊戲模式**：標準模式、甜點專賣店（只賣甜的和喝的）、素食小館（不用肉和海鮮），以及通關後解鎖的限時挑戰（5 年內拿第一）、逆境開局（本金少、租金兩倍）和觀光夜市（觀光客三倍、租金貴五成）。

## 操作

- 滑鼠或手指：點按鈕、點格子放置；拖曳移動畫面；滾輪或雙指縮放。
- 點攤位、桌子、裝飾可以升級、移動或賣掉；點員工可以換工作。
- 鍵盤：空白鍵暫停/繼續，1～3 調速度，0 暫停，Esc 關閉視窗。
- 右上角可以切換暫停 / 1 倍 / 2 倍 / 4 倍速度，以及開關聲音。

## 存檔

三個存檔欄位，存在瀏覽器的 localStorage。新系統的欄位（年度目標、挑戰書、對手人氣下滑、地點 `map`、關卡 `chal`、搭檔／較勁、美食指南星星）都是選填，舊存檔直接讀得進來。每個月底、每分鐘、切到背景時都會自動存檔。舊版（v1）存檔會自動轉換成新格式（員工補上特質）。新手引導的進度存在 `ob`（第幾課、打開了哪些功能）；沒有這個欄位的舊存檔一律當作已經完成。成就、傳承點數和關卡星星另外存在 `shop.legacy`，新手引導／提示／目標卡片的開關存在 `shop.prefs`。

## 效能

- 人物、設施、文字都會快取成小圖；文字（招牌、金額、對話）依縮放畫成貼圖，不用每格 `fillText`。描邊用畫的時候記下的遮罩算，不讀回像素。
- 不會動的燈（鄰居、路燈、帳篷、店裡燈泡串）合成一張低解析度燈光圖，每格只貼一次；物件排序用物件池，每格不產生新物件。
- 人群互推用數字格子、每兩步算一次；每格最多跑 6 步模擬，慢的手機會讓時間變慢而不是越來越卡。
- 畫質：自動（預設）／高／中／省電。自動模式連續 4 秒平均每格超過 26ms 會降一級（降解析度、關光暈層、少粒子），可在「選單」調整。

畫面分成四層 canvas：`#cv` 世界（天空漸層用 CSS 背景）、`#lt` 低解析度的夜晚暗色遮罩（燈光挖洞）、`#bl` 光暈（`mix-blend-mode: screen`）、`#fxc` 最上層的特效和泡泡。縮放和混色交給瀏覽器合成，手機上比較省電。
