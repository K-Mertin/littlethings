# 捏臉工坊 Face Studio

2D 捏臉小遊戲（pilot MVP）。單一 `index.html`，純 SVG 繪製，不需任何外部函式庫。

## 可以調整的部位
- **臉型**：6 種預設臉型＋臉寬、臉長、下顎、下巴、耳朵滑桿；9 種膚色＋自訂；腮紅、雀斑、美人痣
- **眼睛**：7 種眼型，大小、眼距、高低、眼角角度；瞳孔顏色；睫毛
- **眉毛**：8 種眉型，粗細、長度、高低、角度；眉色（預設跟髮色）
- **鼻子**：6 種，大小、高低
- **嘴巴**：9 種，寬度、高低、唇色
- **髮型**：11 種後髮 × 6 種瀏海自由組合，12 種髮色＋自訂
- **配件**：眼鏡（圓框／方框／墨鏡）、蝴蝶結、耳環、小鬍子
- **衣服**：6 種上衣、顏色、6 種背景

## 功能
- 每個選項都是「套用後的樣子」縮圖
- 全部隨機（`R`）、只隨機目前部位、復原（`Ctrl/Cmd+Z`）
- 存檔到「我的角色」（瀏覽器 localStorage，最多 30 個），下載 800×1000 PNG
- 眼睛會跟著游標／手指轉、會眨眼
- 手機直式：上方預覽、下方面板
