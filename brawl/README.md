# 小夥伴大作戰 Buddy Battle

向《小朋友齊打交》（Little Fighter 2）致敬的橫向格鬥遊戲。Q 版小朋友在台灣老街上和跑出來搗蛋的怪獸對打：拳腳連段、必殺技、撿棍子打、丟石頭，喝珍珠奶茶補血。

整個遊戲就是一個 `index.html`，沒有建置步驟，也沒有圖片或音效檔：角色、背景和聲音都由程式即時畫出、合成。

## 模式
- **闖關模式**：第一關「怪獸大鬧老街」，分四個區域。打完一區會出現「GO →」，往右走進下一區。最後在廟口廣場打魔王岩甲龍，牠血量剩一半時會叫小怪來幫忙。過關會記錄每個難度的最快時間。
- **對戰模式**：在台灣公寓頂樓和 1 到 3 個電腦角色大亂鬥，最後站著的人獲勝。每隔一段時間會從天上掉道具下來。
- 難度：簡單、普通、困難。難度會影響電腦的反應速度、同時圍攻你的人數、防禦和連段的頻率，以及怪獸的攻擊力和血量。

## 操作
| | 手機／平板 | 鍵盤 | 手把 |
|---|---|---|---|
| 移動 | 左半邊拖曳搖桿（任何位置按下都可以） | WASD 或方向鍵 | 左搖桿或十字鍵 |
| 跑步 | 搖桿推到底 | 連按兩下左右，或按住 Shift | 搖桿推到底，或按住 RT |
| 攻擊 | 攻 | J（或 Z） | X |
| 跳 | 跳 | K（或 X、空白鍵） | A |
| 防禦 | 防 | L（或 C） | B |
| 必殺技 | 三顆黃色按鈕 | U / I / O，或經典指令 | Y / RB / LB |
| 暫停 | II | Esc 或 P | Start |

**經典指令**（和原作一樣）：防 → 左或右 → 攻 放第一招、防 → 上 → 攻 放第二招、防 → 下 → 攻 放第三招。

**招式**
- 攻擊連按三下是三段連招，第三下會把對手打倒。跑步中攻擊是飛踢，跳起來攻擊是空中踢。
- 跑步中按防禦會翻滾，翻滾時無敵。
- 防禦只擋得住前面來的攻擊。擋太多下會被破防暈眩。
- 被打倒後爬起來會短暫無敵。
- 血條上暗紅色的部分是「可回復的傷」，一段時間沒被打就會慢慢補回來，跟原作一樣。

**道具**：站在道具旁按攻擊就會撿起來。
- 木棍：拿著攻擊範圍更長、打得更痛，跑步中按攻擊可以丟出去，大約打十下會斷。
- 石頭：按攻擊丟出去。
- 珍珠奶茶：補血。冬瓜茶：補氣。

## 角色
必殺技要用藍色的「氣」，氣會慢慢回復，打中對手也會回氣。氣條上的小刻度標出每招需要的量。

| 角色 | 特色 | 第一招 | 第二招 | 第三招 |
|---|---|---|---|---|
| 阿烈 | 火拳少年，平均型 | 火焰波（75） | 升龍拳（100）：起手無敵，往上打飛 | 百裂拳（150）：連打往前推，最後一拳打飛 |
| 小雪 | 冰之少女，控場 | 冰球（75）：把對手凍成冰塊，再打一下就碎 | 冰柱陣（125）：地面一路冒出冰柱 | 冰霜旋風（175）：把周圍的人拉近，最後全部凍住 |
| 阿岩 | 大力士，慢但耐打 | 猛牛衝（75）：衝撞時不會被打斷 | 震地拳（100）：跳起來砸地，震飛周圍的人 | 鋼鐵之軀（150）：8 秒內傷害減半、不會被打斷 |
| 小飛 | 忍者，最快但最脆 | 三連鏢（50）：空中也能丟 | 影步斬（100）：瞬移到最近的敵人背後砍 | 疾風斬（125）：衝過去砍一排，期間無敵 |

## 怪獸
| 怪獸 | 行為 |
|---|---|
| 野豬仔 | 雜兵，用頭頂人，會從遠處衝撞，也會去撿地上的棍子和石頭 |
| 彈弓猴 | 保持距離用彈弓射果子，被近身會逃開 |
| 大笨熊 | 又大又耐打，輕拳打不斷牠，會跺地震飛周圍的人 |
| 小蝙蝠 | 在半空飛，會俯衝咬人，被打倒會掉到地上 |
| 岩甲龍（魔王） | 吐石彈、跺地、衝撞，攻擊時不容易被打斷 |

怪獸被打倒後會「噗」一聲變成一團煙消失。

## 手機與平板
有觸控螢幕時自動顯示觸控按鈕。橫放畫面最大；直放也能玩，畫面在上、按鈕在下。

## 程式結構
- 世界座標：`x` 左右、`z` 前後深度、`y` 高度。模擬固定每秒 60 步，與畫面更新率無關。
- 每個角色都由一個「控制器」填寫同一種 `Input`（移動、跑、攻、跳、防、必殺技）。玩家用 `LocalCtl`（同時聽鍵盤、觸控和所有手把），電腦用 `AICtl`。之後要加多人，只要給第二位玩家一個只聽某一支手把或某一組按鍵的控制器即可；連線對戰也可以從同一個介面接上。
- 角色是一副小骨架（髖、軀幹、頭、雙手雙腳），每個動作是一組關節角度（`pose()`）。主角和怪獸共用骨架，怪獸只是換了頭（`drawHair` 裡的 `boar`、`monkey`、`bear`、`dragon`）、尾巴和毛色；蝙蝠另外畫（`drawBat`）。
- 招式資料：一般攻擊在 `ATK`（起手、判定、收招的影格與打擊範圍），必殺技在 `SKILLS`（耗氣、每一格要做的事、動作）。
- 關卡在 `STAGES`：每個區域有幾波敵人、地上的道具，魔王區有血量剩一半時的援軍。

### 新增角色
在 `CHARS` 加一筆：`look`（髮型或動物頭、衣服顏色）、`hp`、`spd`、`pow`、`combo`（三段連招用哪些 `ATK`）、`skills`（三招必殺技的 `SKILLS` 名稱）。要能被玩家選，再把 id 加進 `HEROES`。
