# 小夥伴大作戰 Buddy Battle

向《小朋友齊打交》（Little Fighter 2）致敬的橫向格鬥遊戲。Q 版小朋友在台灣的老街、夜市、茶園和漁港，和跑出來搗蛋的動物怪獸對打：拳腳連段、必殺技、撿棍子和雨傘打、丟拖鞋和鞭炮，喝珍珠奶茶、吃雞排補血。可以一個人玩，也可以兩個人擠同一台，或是三、四個人各拿一支手機當手把。

沒有建置步驟，也沒有圖片或音效檔：角色、背景和聲音都由程式即時畫出、合成。用手機當手把時才會從 CDN 載入 PeerJS 和 QR code 函式庫。

## 模式
- **闖關模式**：四關，打通一關才開下一關。每關有四個區域，打完一區會出現「GO →」往右走，最後一區打魔王。開頭和結尾有簡短的劇情對話（可以跳過）。過關會記錄每個難度的最高分。
  | 關卡 | 場景 | 怪獸 | 魔王 |
  |---|---|---|---|
  | 第一關・怪獸大鬧老街 | 台灣老街、廟口 | 野豬仔、彈弓猴、大笨熊、小蝙蝠 | 岩甲龍：吐石彈、跺地、衝撞 |
  | 第二關・夜市大混亂 | 晚上的夜市 | 石虎、野豬仔、彈弓猴、大笨熊、小蝙蝠 | 狸貓大王：丟包子、肚皮彈、敲鼓震地 |
  | 第三關・山上的茶園 | 茶園、涼亭 | 台灣藍鵲、石虎、野豬仔、彈弓猴、大笨熊 | 黑熊王：大吼震退、跳起來砸地、衝撞 |
  | 第四關・漁港決戰 | 漁港、碼頭 | 螃蟹兵、小章魚、台灣藍鵲、石虎、野豬仔、大笨熊 | 大章魚：噴墨、觸手橫掃、叫小章魚 |
- **對戰模式**：大亂鬥（各自為戰）或組隊（2 對 2），可以加 0 到 3 個電腦角色。可以選 1、3、5 條命，不限時或 2、3 分鐘（時間到比剩下的命和血）。每隔一段時間會掉道具下來。
  | 場地 | 特色 |
  |---|---|
  | 公寓頂樓 | 水塔、曬衣繩 |
  | 夜市 | 機車會騎過去，先響喇叭、出現警告 |
  | 公園 | 寬敞，沒有機關 |
  | 捷運站 | 列車進站時會把月台邊的人撞飛 |
  | 海邊 | 定時漲潮，把人往前推 |
- **練習場**：公園裡有兩個稻草人。一步一步教走路、跳、跑、翻滾、連招、防禦、必殺技、撿道具和丟道具（提示會依你用觸控、鍵盤或手把顯示不同按法），學完可以自由練習。
- 難度：簡單、普通、困難。會影響怪獸出招的間隔、同時圍攻你的數量、防禦和連段的頻率，以及攻擊力和血量。闖關的命數也不同（3／2／1 條）。

## 幾個人玩
- **1 人**：鍵盤、觸控、手把都可以。
- **2 人（同一台）**：平板橫放，1P 用左半邊、2P 用右半邊的搖桿和按鈕。鍵盤：1P 用 WASD＋J K L（U I O 必殺），2P 用方向鍵＋數字鍵 1 2 3（4 5 6 必殺），沒有數字鍵可用 . / ,。也可以各插一支手把。
- **手機當手把（1–4 人）**：一個人想用手機當遙控器也可以，三、四個人一起玩也是用這個。大螢幕（電視、電腦或平板）選這個模式按「出發！」，畫面會出現 QR code 和房間號碼。每個人用手機掃 QR code、輸入名字、選角色，手機就變成手把：左邊拖曳移動（推到底跑步），右邊攻／跳／防和三個必殺技，上面有自己的血條和氣條，被打會震動。任何一支手機都可以按「開始」、翻劇情、暫停、在結算畫面按「再來一場」。大螢幕也可以按「這台鍵盤也加入」，讓一個人用鍵盤玩。
  - 大螢幕會沿用上次的房間號碼，所以手機上留著的舊網址通常還能用；手機上也可以直接改房間號碼，或在選角畫面按「換房間」。大螢幕按「換一個號碼」會開新房間。
  - 手機斷線（例如螢幕關掉）時，大螢幕上那個人的血條旁會顯示「斷線」，角色站著不動；重新打開網頁按加入，會回到原本的位置。
  - 組隊模式有 3–4 個真人時，1P、3P 是太陽隊，2P、4P 是月亮隊，電腦補到人少的那隊。
  - 遊戲要放在網站上（例如 GitHub Pages），手機和大螢幕都要能上網。

## 操作
| | 手機／平板 | 鍵盤 | 手把 |
|---|---|---|---|
| 移動 | 拖曳搖桿（任何位置按下都可以） | WASD 或方向鍵 | 左搖桿或十字鍵 |
| 跑步 | 搖桿推到底 | 連按兩下左右，或按住 Shift | 搖桿推到底，或按住 RT |
| 攻擊 | 攻 | J（或 Z） | X |
| 跳 | 跳 | K（或 X、空白鍵） | A |
| 防禦 | 防 | L（或 C） | B |
| 撿／丟東西 | 撿（拿著東西時變成「丟」） | E（或 ;） | LT |
| 必殺技 | 三顆黃色按鈕 | U / I / O，或經典指令 | Y / RB / LB |
| 暫停 | II | Esc 或 P | Start |

**經典指令**（和原作一樣）：防 → 左或右 → 攻 放第一招、防 → 上 → 攻 放第二招、防 → 下 → 攻 放第三招。鍵盤畫面下方會顯示按鍵提示（H 可以關掉）。

**招式**
- 攻擊連按三下是三段連招，第三下會把對手打倒。跑步中攻擊是飛踢，跳起來攻擊是空中踢。
- 跑步中按防禦會翻滾，翻滾時無敵。
- 防禦只擋得住前面來的攻擊。擋太多下會被破防暈眩。
- 被打倒後爬起來會短暫無敵。
- 血條上暗紅色的部分是「可回復的傷」，一段時間沒被打就會慢慢補回來，跟原作一樣。

**道具**：站在道具旁按「撿」撿起來，手上有東西時再按一次就丟出去；拿著東西按攻擊就是用它打。
| 道具 | 用法 |
|---|---|
| 木棍 | 拿著打得更遠更痛，打大約十下會斷 |
| 雨傘 | 拿著打；拿著防禦會撐開傘，前面來的攻擊全部擋掉 |
| 石頭 | 丟出去（拿著也能打） |
| 拖鞋 | 丟出去，飛得快，打中會讓對手暈一下 |
| 鞭炮 | 丟出去，落地後炸開 |
| 珍珠奶茶 | 補血 |
| 雞排 | 補很多血，要吃一下子 |
| 冬瓜茶 | 補氣 |

## 角色
每人有兩招必殺技和一個**大絕招**。
- 前兩招用藍色的「氣」：氣會慢慢回復，打中對手也會回氣；氣條上的小刻度標出每招需要的量。
- 大絕招用金色的「絕招能量」：打人和被打都會集能量，集滿時血條下的金條會閃、第三顆按鈕會發光，大約一場能放一次。
- 放大絕招時畫面會暗下來、跳出角色大頭和招式名，出招期間無敵，打全畫面或大範圍、不能防禦。

| 角色 | 特色 | 第一招 | 第二招 | 大絕招 |
|---|---|---|---|---|
| 阿烈 | 火焰，連續壓制 | 火焰波（70）：穿過一排 | 火焰旋風腳（100）：邊轉邊往前燒，最後一腳踢飛 | 火鳳凰：火鳥燒過整個畫面 |
| 小雪 | 冰，控場 | 冰球（75）：把對手凍成冰塊 | 冰滑道（100）：滑過去把人鏟倒 | 暴風雪：全畫面的敵人凍住 |
| 阿岩 | 力量，硬碰硬 | 猛牛衝（75）：衝撞時不會被打斷 | 舉大石（110）：舉起大石頭丟出去，落地碎開 | 大地震：地上所有敵人震飛 |
| 小飛 | 忍者，快 | 三連鏢（50） | 分身術（110）：兩個影分身跟著一起打、一起丟鏢 | 千本手裡劍：天上下起手裡劍雨 |
| 小雷 | 雷電，連鎖（打通第一關解鎖） | 雷電球（70）：打中會麻痺 | 連鎖閃電（100）：在敵人之間跳四次 | 雷神降臨：全場每個敵人被劈三次 |
| 阿風 | 風，吹飛（打通第二關解鎖） | 旋風彈（75）：把人捲起來連續打 | 風之跳（90）：跳很高再往下衝 | 超級龍捲風：大龍捲風橫掃畫面 |
| 小咪 | 召喚（打通第三關解鎖） | 叫豆豆（100）：小狗豆豆來幫忙 | 加油打氣（120）：幫自己和附近的隊友補血 | 動物大遊行：一群動物衝過畫面 |
| 小月 | 星星魔法 | 星星彈（70）：三顆會追人的星星 | 變變變（110）：把敵人變成小青蛙（只能走和跳） | 流星雨：流星一顆顆砸下來 |
| 波波 | 泡泡魔法 | 泡泡（80）：把敵人包進泡泡飄起來，再打一下就破 | 水之盾（100）：擋掉接下來三次攻擊 | 大海嘯：一波大浪沖過畫面 |

魔王不會被變成青蛙或包進泡泡。

怪獸被打倒後會「噗」一聲變成一團煙消失。螃蟹兵的殼擋得住正面的攻擊，要跳起來打或繞到背後；小章魚的墨會讓人變慢。

| `js/core.js` | 共用工具、存檔、音效與配樂合成、輸入（鍵盤、觸控、手把） |

| `js/magic.js` | 第二套必殺技、大絕招、魔法角色（小月、波波）和平衡調整 |
| `js/ai.js` | 電腦角色（怪獸輪流出手的節奏、撿道具、閃避） |

| `js/scenes.js` | 背景（老街、夜市、茶園、漁港、頂樓、公園、捷運站、海邊）、子彈和特效 |

## 程式結構
- 世界座標：`x` 左右、`z` 前後深度、`y` 高度。模擬固定每秒 60 步，與畫面更新率無關。
- 每個角色都由一個「控制器」填寫同一種 `Input`（移動、跑、攻、跳、防、必殺技）。本機玩家用 `HumanCtl`（聽分配給他的鍵盤按鍵、觸控板和手把），電腦用 `AICtl`，練習場的稻草人用 `DummyCtl`，手機玩家用 `RemoteCtl`。
- 手機手把：手機每次狀態改變（最多每秒 30 次）和每 150 毫秒送出一次「按住的狀態＋每顆按鈕累計按了幾下」，大螢幕比對累計次數產生按鍵，所以訊息遺失或合併也不會少按。連線用 PeerJS（WebRTC），房間號碼就是大螢幕在 PeerJS 伺服器上的名字。網址加 `?net=local` 會改用 BroadcastChannel，可以在同一台電腦開兩個分頁測試（大螢幕 `index.html?net=local`，手把用大廳顯示的網址）。
- 角色由浮動的頭、身體、拳頭和鞋子組成（不畫手腳），每個動作是一組關節角度（`pose()`）。主角和多數怪獸共用骨架，只換頭、尾巴和毛色；螃蟹、章魚、藍鵲、蝙蝠、小狗和稻草人另外畫（`DRAWERS`）。
- 畫面效果：圓形部位有亮面和陰影（`softShade`），表情跟著動作換；重擊會停格、閃白、跳出「砰！」（`burst`），被打飛和衝刺會留下殘影（`trackGhosts`），放必殺技會發光並喊出招式名。每個場景最前面有一層深色剪影前景（`FOREGROUNDS`），捲動得比角色快，有人走到後面時會變淡。
- 招式資料：一般攻擊在 `ATK`（起手、判定、收招的影格與打擊範圍），必殺技在 `SKILLS`（耗氣、每一格要做的事、動作）。
- 存檔在 `localStorage`，名稱都以 `buddybattle.` 開頭（選的角色、難度、過關紀錄、最高分）。

### 新增角色
在 `CHARS` 加一筆：`look`（頭型、衣服顏色）、`hp`、`spd`、`pow`、`combo`（三段連招用哪些 `ATK`）、`skills`（三招必殺技的 `SKILLS` 名稱）。要能被玩家選，再把 id 加進 `HEROES`；要過關才解鎖就加 `unlockStage`（第幾關，從 0 算）和 `unlock`（顯示的說明）。

### 新增關卡
在 `STAGES` 加一筆：`theme`（背景，對應 `THEMES`）、`music`、每個區域的 `waves`（每波出哪些怪，`:L` 代表從左邊進來）和地上的 `items`，最後一區放魔王。劇情寫在 `STORY` 的 `intro<n>`／`outro<n>`。
