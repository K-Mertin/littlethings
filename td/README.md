# 守塔奇兵 · Tower Keepers

經典塔防遊戲。敵人沿著道路走向城堡，在路旁的空地蓋塔擋住牠們，再指揮一位英雄在路上迎戰，撐過所有波次就過關。

## 怎麼玩

- **蓋塔**：點空地 → 在面板選一座塔 → 再點一次確認。電腦上可以先按 `1`–`7` 再點地圖（按住 Shift 可以連續蓋）。
- **升級**：點已經蓋好的塔，Lv1 → Lv2 → Lv3，最後在兩種專精中選一種。也可以切換攻擊目標（最前／最後／最強／最近）或賣掉（開打前賣掉全額退費）。
- **波次**：面板會預告下一波的敵人。一波出完之後會倒數，提早叫下一波可以多拿金幣。可切換 1×／2×／3× 速度。
- **技能**：隕石（點地圖選位置）、冰封（凍住全場）。
- **英雄**：出征前選一位英雄（騎士雷歐、遊俠小嵐、法師露米）。點英雄再點道路就會走過去（也可以按面板上的英雄頭像或 `H`）。英雄會自動攻擊、技能好了自動放（也能在英雄面板手動按，`E`／`R`），倒下後會回城堡休養再重生。經驗跨關卡保存，最高 10 級，第 3 級學會第二個技能；騎士會擋住路上的敵人。
- **星星**：剩下的生命越多星星越多（最多 3 顆），困難過關再加 2 顆；打贏第 4 關後解鎖無盡模式，每撐過 10 波 1 顆；關卡挑戰每個 1 顆。星星可以在「天賦樹」換永久加成，隨時可以重置。
- 鍵盤：`U`/`I` 升級（左／右專精）、`S` 賣、`T` 換目標、`Q` 隕石、`W` 冰封、`H` 選英雄、`E`/`R` 英雄技能、`N` 下一波、`F` 速度、`空白` 暫停、`M` 靜音。

## 內容

- 14 張手工地圖：單一路線、雙入口、交叉路口、岔路分流；第 11–14 關各有特殊地形：
  - 天空浮島：**傳送陣**（敵人從一座島跳到另一座）、大量飛行敵人，頭目雷霆巨鷹。
  - 水晶礦坑：昏暗的礦坑，地上的**水晶基座**讓蓋在上面的塔傷害 +25%、射程 +10%，頭目晶甲巨蟲會鑽地。
  - 沙暴遺跡：每隔一陣子刮**沙暴**，所有塔射程暫時變成八成；木乃伊打倒一次會再站起來，頭目沙漠法老。
  - 海底神殿：三個入口，路上的**海流**讓敵人加速，最終頭目深淵海妖會噴墨讓塔暫時停擺。
- 每關三個挑戰：限定塔種、無技能、鐵人（1 條命），各得 1 顆星。
- 27 個成就；無盡模式每 5 波換一個詞綴（疾風、鐵壁、再生、蜂群、天空之怒、豐收），每 5 波精英巨魔、20 波後頭目帶副手。
- 7 種塔：箭塔、砲塔、冰霜塔、法師塔、狙擊塔、戰旗（增益）、金礦（經濟），各有 3 級＋2 種專精。
- 23 種敵人：快速、重甲、抗魔、飛行、補血、護盾、分裂、巨魔、召喚小兵、風精靈、晶甲蛛、會復活的木乃伊、鐵螯蟹，以及岩石巨人王、炎龍、巫妖王、雷霆巨鷹、晶甲巨蟲、沙漠法老、深淵海妖七個頭目。每種敵人都有走路和攻擊（被英雄擋住時）動畫。
- 簡單／普通／困難三種難度、無盡模式、天賦樹。
- 音效與配樂全部用 WebAudio 即時合成，沒有音檔；所有圖也都是程式即時畫的（會先畫進離屏畫布快取），沒有圖檔。
- 選關是一張手繪風的世界地圖；「圖鑑」可以看所有塔（含各等級與專精）、英雄和遇過的敵人。
- 畫面：角色用三階明暗＋輪廓亮邊（快取時一次算好）；加色特效有亮度上限，爆炸疊在一起也不會整片發白。
- 效能：連續一段時間掉到 40fps 以下會自動降低解析度與特效（`__td.quality(0|1|2)` 可手動指定）。

## 檔案結構

```
td/
  index.html      版面與樣式
  js/util.js      小工具、亂數、存檔（localStorage）
  js/data.js      塔、敵人、地圖、難度、天賦樹的數值（擴充主要改這裡）
  js/waves.js     出怪表產生器（每關固定種子）＋無盡模式
  js/sim.js       遊戲邏輯（不碰 DOM，可以在 Node 裡做平衡模擬）
  js/hero.js      英雄的邏輯（移動、擋怪、攻擊、技能、升級；不碰 DOM）
  js/bot.js       電腦玩家（標題畫面示範戰鬥與平衡測試用，也會移動英雄）
  js/gfx.js       繪圖基礎：顏色、雜訊、離屏畫布快取、外框、柔光貼圖
  js/art.js       防禦塔（各等級與專精、弓箭手等小兵）、城堡、傳送門的美術
  js/beasts.js    敵人美術（10 格走路／拍翅＋6 格攻擊動畫，快取成圖）
  js/heroart.js   英雄美術（待機、走路、攻擊、施法動畫，頭像與立繪）
  js/terrain.js   地形：每個主題的調色盤、地面、道路、水／岩漿、懸崖、裝飾物
  js/fx.js        畫面特效：爆炸、死亡動畫、金幣飛到上方、地面痕跡、環境生物（只在畫面層）
  js/render.js    每幀組合畫面（y 排序、投射物、夜晚光照、橫幅；直式畫面時地圖會轉 90 度）
  js/menus.js     選關世界地圖、圖鑑
  js/audio.js     合成音效與配樂
  js/ui.js        面板、選單、結算畫面
  js/main.js      主迴圈、版面配置、輸入、遊戲流程
```

模擬層只透過 `Hook.fx(...)` 通知畫面特效，特效用自己的亂數，不影響遊戲結果。

測試用掛勾：瀏覽器主控台的 `window.__td`（例如 `__td.start(0,'normal')`、`__td.bot(true)`、`__td.ff(60)`、`__td.selHero()`、`__td.heroMove(x,y)`、`__td.heroCast(0)`）。
