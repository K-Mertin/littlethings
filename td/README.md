# 守塔奇兵 · Tower Keepers

經典塔防遊戲。敵人沿著道路走向城堡，在路旁的空地蓋塔擋住牠們，撐過所有波次就過關。

## 怎麼玩

- **蓋塔**：點空地 → 在面板選一座塔 → 再點一次確認。電腦上可以先按 `1`–`7` 再點地圖（按住 Shift 可以連續蓋）。
- **升級**：點已經蓋好的塔，Lv1 → Lv2 → Lv3，最後在兩種專精中選一種。也可以切換攻擊目標（最前／最後／最強／最近）或賣掉（開打前賣掉全額退費）。
- **波次**：面板會預告下一波的敵人。一波出完之後會倒數，提早叫下一波可以多拿金幣。可切換 1×／2×／3× 速度。
- **技能**：隕石（點地圖選位置）、冰封（凍住全場）。
- **星星**：剩下的生命越多星星越多（最多 3 顆），困難過關再加 2 顆；打贏第 4 關後解鎖無盡模式，每撐過 10 波 1 顆。星星可以在「天賦樹」換永久加成，隨時可以重置。
- 鍵盤：`U`/`I` 升級（左／右專精）、`S` 賣、`T` 換目標、`Q` 隕石、`W` 冰封、`N` 下一波、`F` 速度、`空白` 暫停、`M` 靜音。

## 內容

- 8 張手工地圖：單一路線、雙入口、交叉路口、岔路分流。
- 7 種塔：箭塔、砲塔、冰霜塔、法師塔、狙擊塔、戰旗（增益）、金礦（經濟），各有 3 級＋2 種專精。
- 15 種敵人：快速、重甲、抗魔、飛行、補血、護盾、分裂、巨魔、召喚小兵，以及岩石巨人王、炎龍、巫妖王三個頭目。
- 簡單／普通／困難三種難度、無盡模式、天賦樹。
- 音效與配樂全部用 WebAudio 即時合成，沒有音檔；所有圖也都是程式即時畫的（會先畫進離屏畫布快取），沒有圖檔。
- 選關是一張手繪風的世界地圖；「圖鑑」可以看所有塔（含各等級與專精）和遇過的敵人。

## 檔案結構

```
td/
  index.html      版面與樣式
  js/util.js      小工具、亂數、存檔（localStorage）
  js/data.js      塔、敵人、地圖、難度、天賦樹的數值（擴充主要改這裡）
  js/waves.js     出怪表產生器（每關固定種子）＋無盡模式
  js/sim.js       遊戲邏輯（不碰 DOM，可以在 Node 裡做平衡模擬）
  js/bot.js       電腦玩家（標題畫面示範戰鬥用）
  js/gfx.js       繪圖基礎：顏色、雜訊、離屏畫布快取、外框、柔光貼圖
  js/art.js       防禦塔（各等級與專精、弓箭手等小兵）、城堡、傳送門的美術
  js/beasts.js    敵人美術（10 格走路／拍翅動畫，快取成圖）
  js/terrain.js   地形：每個主題的調色盤、地面、道路、水／岩漿、懸崖、裝飾物
  js/fx.js        畫面特效：爆炸、死亡動畫、金幣飛到上方、地面痕跡、環境生物（只在畫面層）
  js/render.js    每幀組合畫面（y 排序、投射物、夜晚光照、橫幅；直式畫面時地圖會轉 90 度）
  js/menus.js     選關世界地圖、圖鑑
  js/audio.js     合成音效與配樂
  js/ui.js        面板、選單、結算畫面
  js/main.js      主迴圈、版面配置、輸入、遊戲流程
```

模擬層只透過 `Hook.fx(...)` 通知畫面特效，特效用自己的亂數，不影響遊戲結果。

測試用掛勾：瀏覽器主控台的 `window.__td`（例如 `__td.start(0,'normal')`、`__td.bot(true)`、`__td.ff(60)`）。
