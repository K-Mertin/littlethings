# 燼燈 · Emberlight

給大人玩的探索型「銀河惡魔城」（Metroidvania），風格參考 Hollow Knight、Metroid。
一張相連的大地圖（25 個房間、5 個區域），打倒頭目拿到新能力，再回頭打開以前過不去的路。
畫面全部用 Canvas 2D 程式畫（沒有圖片素材、沒有外部套件、沒有建置步驟），音效和背景音也是 WebAudio 即時合成。

故事：灰燼城的王把所有靈魂送進爐心，火燒了三百年。主角提著一盞燼燈往下走，要把燈放進爐心讓火安息。
石碑（↑ 閱讀）上有零碎的故事。

## 操作
| 鍵盤 | 手把 | 觸控 | 動作 |

| ← → ／ A D | 左類比／十字鍵 | ◀ ▶ | 移動 |
| Z ／ 空白鍵 | A | 跳 | 跳（按住跳更高；有二段跳之後在空中再按一次） |
| X ／ J | X | 砍 | 攻擊；按住 ↑ 往上砍，空中按住 ↓ 往下劈（打到敵人或尖刺會彈起來） |
| C ／ Shift ／ K | B／RB | 衝刺 | 衝刺 |
| 長按 V ／ L | Y | 回復 | 站著不動，花一格「燼」回復 1 格生命 |
| ↑ |  | ▲ | 在篝火休息存檔、讀石碑 |
| ↓ ＋ Z |  | ▼＋跳 | 往下穿過薄平台 |
| M ／ Tab | Back | 地圖 | 地圖 |
| Esc ／ P | Start | 暫停 | 暫停 |

- 打中敵人累積「燼」（左上的圓），存滿一格可以回復。燼瓶（flask）道具讓燼的上限變多。
- 碰到尖刺、岩漿：扣 1 格生命，回到剛剛站穩的地方。生命歸零：回到最後休息的篝火（地圖、能力、道具都保留）。
- 篝火休息會補滿生命、重生所有一般敵人。

## 檔案
- `index.html`：畫面（標題、暫停、說明、結局、對話框）、觸控按鈕、CSS。
- `js/world.js`：**地圖資料**。`EM.buildWorld()` 用 `room(id, 格x, 格y, 寬, 高, 區域, 名稱, build)` 一間一間蓋。
  一個房間格子是 24×14 磚（一磚 32px），整張世界 9×8 格。`build` 裡用相對座標的小工具：
  `fill`、`set`、`floor`、`plat`（單向薄平台）、`ladder`、`door`（同時挖開兩邊的牆）、`gate`（頭目門）、`enemy`、`bench`、`item`、`tablet`、`mover`、`crusher`、`jet`、`boss`、`decor`。
  區域配色在 `EM.AREAS`（`dark` 是黑暗程度，越大越暗）。
- `js/core.js`：物理常數 `EM.PHY`、輸入（鍵盤＋觸控＋手把）、存檔、主角移動與攻擊、地形碰撞。
- `js/actors.js`：敵人（crawler、moth、spitter、hopper、charger、shield、jelly）、四個頭目、投射物、篝火／石碑／道具／房間切換。
- `js/render.js`：繪圖（地形貼圖快取、各區背景、光影、HUD、地圖）。
- `js/main.js`：音效與背景音、畫面流程、主迴圈（固定 1/120 秒）、測試用的 `window.__ember`。

## 物理數字（`EM.PHY`）
跑 220、跳 520（約 2.8 磚高）、二段跳 460（再 +2.2 磚）、衝刺 640×0.15 秒（約 3 磚）。
設計地圖時：沒有能力能上 2 磚、橫跳 3 磚左右；3 磚以上的高度就需要蹬牆或二段跳。

## 存檔
localStorage `ember.v1`：
`{ v:1, bench, abil:{dash,wall,double}, maxHp, maxFlask, items[], bosses[], walls[], visited[], benches[], sigils, deaths, time, done, mute, read[] }`。
**改格式要做遷移**（`v` 欄位就是為了這個），不然玩家的進度會不見。

## 測試
`window.__ember`：`start(存檔覆寫)`（不會寫入 localStorage）、`step(n)`（固定 1/120 秒）、`hold = true`（停掉自動更新）、
`fast = true`（關音效粒子）、`goto(房間id, x, y)`、`closeDialog()`、`G`（整個遊戲狀態）、`IN`（輸入）。
上架前用 best-first 搜尋（真實物理、0.1 秒一個動作）跑了 49 段路線：該通的通、需要能力的地方沒有能力時確定過不去；
四個頭目用簡單的機器人打過，確認打得死、能力光球／印記／結局都正常。
