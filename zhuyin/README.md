# ㄅㄆㄇ 小島

給幼兒園孩子的繁體中文注音符號練習。好朋友（吉祥物）用台灣腔的語音帶著孩子玩，可以在首頁按 🐾 換成企鵝、藍鵲、兔兔、狗狗或貓貓（開始畫面點吉祥物也會換；預設企鵝）。故事裡的「小藍」是一隻小企鵝，不需要識字。和 ABC Island 一樣：平板優先（橫放直放都可以），手機、電腦也能玩；只用點的，按鈕夠大；沒有扣分、倒數或失敗畫面。

## 注音課程（首頁最上面的 🗺️）
37 課照教學順序排成一條地圖路線，上完一課才開下一課，每課完成送一張貼紙：
- 第 1–10 課：新符號（ㄅㄆㄇㄈ → ㄉㄊㄋㄌ → … → ㄢㄣㄤㄥㄦ）。每課：🧑‍🏫 小藍教一教（每個新符號：念兩次 → 嘴巴和舌頭怎麼放 → 換你念 → 2–3 個例詞、符號標紅 → 筆順動畫和幾筆）→ 👂 聽音找注音（只考學過的，新的優先）→ ✏️ 寫一個新符號（跟著箭頭）→ 🍉 第一個音或 🧩 拼拼看（只用學過的符號拼得出來的字）
- 第 11 課四聲（先教：球沿著聲調線條走，配「一聲平平的…」說明和媽麻馬罵）、第 12 課拼一個字（先教：注音卡片亮起來合成一個音，ㄇ＋ㄚ→媽、加上三聲→馬、ㄏ＋ㄨ＋ㄚ→花，再換你拼）、第 13–15 課結合韻（先教：ㄧ＋ㄚ→ㄧㄚ 的合成動畫和例詞）、第 16 課拼兩個字（先教：西瓜一個字一個字拼）、第 17–20 課讀小故事、第 21–22 課看注音找圖、第 23–28 課再讀六本小故事、第 29 課寫字的注音、第 30 課讀短句、第 31 課寫詞的注音（第 21、30 課先由小藍示範怎麼只看注音讀：一個音一個音念再拼起來、一句話一個字一個字讀；第 29、31 課先示範寫「貓」的注音：拆音、照筆順寫、選聲調）、第 32–37 課讀短文
- 上方會顯示「第幾課」和這課的步驟，做到哪一步

## 活動
| 首頁按鈕 | 內容 |
|---|---|
| ㄅㄆㄇ 認識注音 | 37 個注音分兩頁（聲母／介音・韻母），點一個就聽「ㄅ，包子的ㄅ」，旁邊有圖和例字的注音。聽過的會打綠點 |
| 👂 聽音找注音 | 小藍念一個注音，從三個裡找出來。答錯會念出點到的是什麼，對的會發亮，這題稍後再考。答對兩次以上的符號，會開始混進聽起來很像的（ㄅㄆ、ㄓㄗ、ㄣㄥ…） |
| ✏️ 寫注音 | 37 個注音都可以寫。每個三個階段：跟著紅色虛線和箭頭（有筆順編號和綠色起點）→ 只有淡淡的字 → 自己寫（寫錯才出現綠點）。每一筆檢查起點、終點和沿路的點，方向寫反不算；容忍度寬。按 👀 看示範。三顆星都拿到送一張貼紙 |
| ✏️ 寫字的注音（寫注音的第二個分頁） | 看圖聽一個字（貓），在寫字板上把注音一個一個寫出來（ㄇ、ㄠ），每一筆都檢查筆順；寫完一個符號就放進旁邊直排的格子。一開始沒有提示，寫錯三次或按 💡 會出現淡淡的字和起點。最後點選第幾聲。第三個分頁「寫詞的注音」：兩個字的詞（烏龜、熱狗…），一個字一個字寫，每個字寫完選聲調（多了輕聲） |
| 🍉 第一個音 | 看圖聽詞（西瓜），找出第一個注音（ㄒ）。答對後字旁邊會出現注音，第一個音標紅 |
| 🧩 拼拼看 | 「一個字」：看圖聽字（貓），把注音一個一個放進直排的格子（ㄇ、ㄠ），拼完念「ㄇ，ㄠ，貓！」並標上聲調。前 12 個字只拼兩個符號的，之後加入有介音的（ㄏㄨㄚ 花）。「兩個字」：70 個詞（西瓜、飛機…），一個字一個字拼 |
| ㄧㄚ 結合韻 | 「聽一聽」：20 個結合韻（ㄧㄚ、ㄨㄛ、ㄩㄝ…），點了會念「ㄧ，ㄚ，ㄧㄚ。鴨子的ㄧㄚ」；「考考你」：聽音找結合韻，干擾選項是同介音或同韻母的 |
| ˉˊˇˋ 四聲 | 「聽一聽」：媽麻馬罵等 12 組，每張卡有聲調的線條；「考考你」：聽一個字，選第幾聲 |
| 📚 小故事 | 10 本原創小故事（小藍的早上、下雨了、去公園、好朋友、去海邊、生日快樂、小種子、動物園、晚安、好多顏色），每本 5 頁。每個字旁邊有注音，小藍念的時候字會依序變紅；點一個詞可以聽那個詞（「的」「了」不單獨念）。讀完回答 2 題看圖選答案。另一個分頁「看注音找圖」只顯示注音、不念題目，自己讀再選圖；「讀短句」只顯示一整句的注音（20 句，例如ㄒㄧㄠˇ ㄇㄠ ㄗㄞˋ ㄕㄨㄟˋ ㄐㄧㄠˋ），讀完選出對的圖，答對才出現國字並念出來；「讀短文」6 篇兩三句的短文（小狗和球、三顆蘋果…），只顯示注音，按「我讀好了」後聽題目看圖回答 2 題，答完才出現國字並念一遍 |
| 📒 貼紙簿 | 每完成一輪（或一課）得到一張貼紙。貼紙有 8 類、共 128 種（森林動物、海洋、花園、好吃的、交通工具、天空、玩具、魔法王國），沒拿過的優先。6 本場景貼紙簿（草原、海底、太空、城堡、我的房間、小島）：從下面的貼紙盒把貼紙拖到圖上，想放哪裡就放哪裡；點一下變大變小；拖到圖外面就收回盒子。「收集冊」看每一類收集了幾張 |

任何時候點小藍，他會再說一次。

## 筆順
- 37 個注音的筆畫數、順序和方向依教育部《[國字標準字體筆順學習網](https://stroke-order.learningweb.moe.edu.tw/phonetic.jsp)》的注音筆順。`data.js` 的 `STROKES` 只存每一筆的中心線（幾個點），畫面上的字是程式依這些點畫出來的。
- 有些注音的筆數可能和一般印象不同（例如 ㄅ、ㄋ、ㄑ、ㄟ、ㄥ 都是一筆），以教育部為準。

## 家長區
按住右上角 ⚙️ 兩秒，再答一題加法：
- 進度：今天玩了多久、貼紙、聽過幾個注音、每個注音答對次數（顏色）、常答錯的、拼過的字、四聲答對題數
- 設定：休息提醒（預設 15 分鐘）、全螢幕、清除進度、回遊戲大廳

進度存在瀏覽器的 localStorage（`zhuyin-v1`）。

## 語音
- 全部台詞預錄在 `audio/`：微軟 Edge 的台灣中文神經語音 **zh-TW-YunJheNeural（雲哲，男聲）**，語速 +5%（2026-10-21 從曉臻 -10% 換過來，和 123 小島一樣），用 [edge-tts](https://github.com/rany2/edge-tts) 錄、ffmpeg 剪掉前後靜音。遊戲用 Web Audio 播放；沒有音檔的句子才用瀏覽器的 zh-TW 語音。
- 台詞都寫在 `data.js` 的 `P`，`allLines()` 會列出每一句。`audio/phrases.tsv` 是「id、文字」，id 是文字的 FNV-1a 32-bit 雜湊。
- 改了台詞或加了字以後：
  ```sh
  node tools/lines.js > audio/phrases.tsv
  python3 -m pip install --user edge-tts
  python3 tools/record.py audio/phrases.tsv audio            # 只錄還沒有的句子
  python3 tools/record.py audio/phrases.tsv audio zh-TW-HsiaoYuNeural   # 換聲音要先刪掉舊音檔
  ```
- 單獨念一個注音（例如 ㄗ）時，語音會念它的名稱，用聲音比對確認過。雲哲會把 ㄅㄆㄇ 念成「ㄅㄜ」，所以這三個在送去錄音前換成同音字（玻、坡、摸，見 `data.js` 的 `spoken()`）；`audio/phrases.tsv` 存的是實際送去念的文字。
- 結合韻不直接把「ㄧㄚ」丟給語音（有幾個會念得不準），而是用同音的一聲字代替（ㄧㄚ 念「鴨」、ㄩㄥ 念「雍」），畫面上還是顯示注音。台詞物件是 `{ text: 念的字, show: 泡泡顯示的字 }`。
- **授權注意**：edge-tts 用的是 Edge「大聲朗讀」的服務，不是有授權的 Azure API。正式公開前打算改用 Azure AI Speech（同一個聲音）重錄。
