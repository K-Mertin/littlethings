# 噗噗的遊戲小屋

向當年「史萊姆的第一個家」好玩遊戲區致敬的小遊戲合輯。打開就能玩，不用安裝，手機、平板、電腦都能玩。遊戲和角色都是原創的；吉祥物是綠色果凍「噗噗」。

## 遊戲

| 遊戲 | 檔案 | 類型 | 操作 |
|---|---|---|---|
| 噗噗下樓梯 | `stairs.html` | 反應 | ←→ / A D；手機按住畫面左半或右半 |
| 水果接接樂 | `catch.html` | 反應（60 秒） | ←→ / 滑鼠；手機左右拖 |
| 敲敲地鼠 | `mole.html` | 反應（45 秒） | 點地鼠；QWE / ASD / ZXC 或數字鍵盤 |
| 大家來找碴 | `spot.html` | 益智（無限關；慢慢找／限時） | 點不一樣的地方；H 用提示 |
| 翻翻記憶 | `memory.html` | 益智（3 種難度） | 點牌；Tab + Enter |
| 十乘十方塊 | `blocks.html` | 益智 | 拖曳方塊；1 2 3 選方塊、方向鍵、Enter |
| 噗噗排球 | `volley.html` | 反應（對電腦／兩人） | ←→↑ 或 ADW；觸控一人一根手指：按住拖＝移動、點一下＝跳、空中點＝殺球 |
| 噗噗小廚房 | `kitchen.html` | 扮家家酒（5 天） | 全部用點的 |
| 噗噗換裝屋 | `dressup.html` | 扮家家酒 | 全部用點的；可拍照存圖 |
| 疊疊高樓 | `stack.html` | 反應 | 點畫面／空白鍵 |
| 噗噗去釣魚 | `fish.html` | 反應（60 秒） | 點水裡；←→ 移動、↓ 放鉤、↑ 收線 |
| 噗噗泡泡龍 | `bubble.html` | 益智（無限關） | 拖曳瞄準放開發射；←→ 瞄準、空白鍵發射、S 交換 |
| 動物連連看 | `link.html` | 益智 | 點兩個；H 提示、R 洗牌 |
| 彩虹倒水瓶 | `pour.html` | 益智（20 關、不限時） | 點瓶子再點另一瓶（或拖過去）；1～9 選瓶、Z 復原、H 提示 |
| 小小著色本 | `color.html` | 畫畫 | 選顏色點區塊；可復原、存圖 |

- **噗噗下樓梯**：普通樓梯補 1 格血，尖刺扣 4 格，天花板扣 5 格；還有彈簧、左右輸送帶、會碎的木板。
- **水果接接樂**：連續接到 6 個 ×2、15 個 ×3；⭐ 50 分，🐌 慢動作 4 秒，💣 碰到三次結束。
- **敲敲地鼠**：金色地鼠 30 分但很快，戴安全帽的要敲兩下，敲到小白兔扣 20 分。
- **大家來找碴**：每關用程式畫一張新圖，有五種主題可選或輪流換：草原小鎮（房子、樹、花、氣球）、海邊沙灘（帆船、陽傘、沙堡、螃蟹、貝殼）、海底世界（魚、珊瑚、海草、水母、寶箱）、下雪天（雪人、聖誕樹、禮物、雪花）、糖果王國（杯子蛋糕、棒棒糖、冰淇淋、甜甜圈），隨機做出 5 個不同（換顏色、少一個、多一個、變大、改細節）。兩種模式：「慢慢找」不限時間、點錯不扣分、提示用不完；「限時挑戰」第一關 150 秒、每關少 10 秒（最少 75 秒），點錯扣 2 秒，找得快會多送一個提示。
- **噗噗排球**：海灘排球，先拿 7 分贏。對電腦有簡單／普通／困難（電腦會依難度偶爾判斷錯誤），或兩人同一台裝置對打（鍵盤左 ADW、右 ←→↑；觸控時各用半個畫面、一根手指）。移動有加減速；接球一定往對面飛，按著往網子方向打得遠、往後按打得高；跳起來球在手邊時按跳立刻殺球（不然會保留 0.45 秒）；所有擊球會自動抬高到剛好過網；沙灘上的虛線圈是預測落點。觸控沒有螢幕按鈕：按住沙灘拖曳，噗噗跑到手指位置；點一下跳（並跑去點的位置）；在空中點或用第二根手指點＝殺球；也可往上快速一撥跳。拿掉貼邊的按鈕是為了避免平板邊緣滑動與多指系統手勢（切換 App），並阻止頁面捲動、縮放與長按選單。
- **噗噗小廚房**：客人點餐（泡麵、烤肉串、餅乾＋配料），點料理台開始煮，煮好放到盤子上、加配料、點客人上菜。放太久會燒焦。五天逐步解鎖新菜色與配料，依招待比例給 0–3 顆星，至少 1 顆星開放下一天。
- **噗噗換裝屋**：顏色、表情、帽子、眼鏡、衣服、手上、背景七類（上方大圖示分頁，有穿戴的分頁會亮粉紅點），隨機搭配、拍照（拍立得相框 PNG）、記住上次造型。
- **疊疊高樓**：樓層吊在吊鉤上左右滑動（兩端會減速折返），點一下鬆開吊鉤讓它掉下去，落地壓扁回彈，超出下層的部分切掉掉落；差 5px 以內算完美，連續三次完美加寬。天空隨高度從白天、夕陽、星空到外太空（飛機、UFO）。
- **噗噗去釣魚**：點水裡的位置，船開過去、魚鉤放到那個深度等 1.6 秒；魚的嘴碰到魚鉤就上鉤自動收線。十種魚依深度、速度、稀有度給分，海底有垃圾和寶物（王冠 200 分）。魚類圖鑑記錄每種釣到幾次。
- **噗噗泡泡龍**：三種難度——🐣 簡單（原本的：顏色少、同色成團、完整反彈瞄準線）、⭐ 普通（預設：顏色較多、較分散、瞄準線只到第一次反彈多一點、第 5 關起有石頭）、🔥 困難（最多 8 色、幾乎不成團、瞄準線只有一小段、石頭多、天花板降得快）。灰色石頭打不破，要把托住它的泡泡打掉讓它掉下來。20 關。8 欄六角格，三個以上同色消除、沒連到天花板的掉落（加倍分）；連續沒消除幾次天花板下降；顏色數和排數隨關卡增加。
- **彩虹倒水瓶**：倒水排序益智。每瓶 3～6 格、3～14 種顏色，通常外加兩個空瓶；第 13～20 關是挑戰關：只有一個空瓶、❓ 神秘瓶（只看得到最上面一層，下面的倒開才會顯現）、13～14 種顏色；只能倒在同色上面或空瓶裡，一次倒完最上面連續的同色。整瓶同一色就蓋上軟木塞、笑一下消失。每題出題時用程式解一遍，保證解得開；💡 提示也是現場解出下一步，卡住會提醒按復原。復原不限次數、每關可加一個空瓶、「重來」回到這題開頭。可選「有小圖案」（每種顏色有自己的形狀，好分辨）或「只看顏色」。
- **動物連連看**：兩種玩法。「🐾 經典」最多轉兩個彎、可繞外框；「🌀 會掉落」線不能出框，消掉後動物會往這關的方向滑（往下掉、往左靠、往上飄、往右靠、左右往中間擠、左右分開、上下往中間擠、上下分開，八關各一種，框外有箭頭提示）。8 關，6×6 起，到 8×10；提示 3 次、洗牌 2 次，沒有可連的會自動洗牌；剩餘時間換獎勵分。
- **小小著色本**：6 張向量線稿（Path2D 區塊），點擊填色有擴散動畫，18 色含橡皮擦，復原、清空、存 PNG，每張圖的顏色存在瀏覽器。
- **十乘十方塊**：排滿一行或一列就消除，同時消多行、連續消除分數加倍。三塊都放不下就結束。

## 慢慢玩（不限時）與選關卡

有計時或關卡的遊戲，開始畫面都能選模式（記住上次的選擇，預設是慢慢玩）：

| 遊戲 | 慢慢玩 | 挑戰 | 選關卡 |
|---|---|---|---|
| 水果接接樂 | 不限時、炸彈只扣 20 分，按頂列「休息一下」結束 | 60 秒、炸彈三次結束 | — |
| 敲敲地鼠 | 不限時、速度上限較低，「休息一下」結束 | 45 秒 | — |
| 噗噗去釣魚 | 不限時，按頂列「收竿」結束 | 60 秒 | — |
| 大家來找碴 | 不限時、點錯不扣、提示用不完 | 150 秒起每關 −10 秒 | — |
| 動物連連看 | 不限時、提示和洗牌用不完 | 限時、剩餘時間換分 | 第 1–8 關（經典／會掉落都能選） |
| 彩虹倒水瓶 | 本來就不限時 | — | 第 1–20 關（3色×3格 到 14色×6格，含一空瓶、❓ 神秘瓶） |
| 噗噗泡泡龍 | 天花板不下降 | 沒消除幾次天花板下降 | 第 1–20 關，另選難度（簡單／普通／困難） |
| 噗噗小廚房 | 客人不會走、食物兩倍時間才焦 | 客人等太久會離開 | 五天都能直接選 |

**玩到一半換關卡／模式**：頂列右邊的「☰」（選關、換模式、選天、換大小）隨時按，遊戲會暫停並打開選單，可以直接選別的關「重新開始」，或按「▶ 繼續玩」（或 <kbd>Esc</kbd>、再按一次 ☰）回到原本的進度。泡泡龍、連連看、倒水瓶、接水果、敲地鼠、釣魚、找碴、小廚房、排球、翻翻記憶都有。

共用工具：`MG.choose({ id, title, html, modes, picks, levels, extra, playing, start })` 畫開始畫面（`picks` 是額外的選項列，例如連連看的玩法，會記住並傳給 `start(mode, level, picks)`）（給 `playing()` 就會自動加上 ☰ 暫停選單）；`MG.pauseMenu({ label, playing, open })` 給自訂開始畫面的遊戲用，`open` 回傳的函式會在「繼續玩」時還原狀態；`MG.barButton(文字, fn)` 在頂列加按鈕（休息一下／收竿）。

## 結構

```
index.html    遊戲區首頁（圖片版／文字版、更新紀錄）
mini.css      共用樣式：頂列、開始／結果視窗
mini.js       共用工具：頂列、畫布縮放、最高分（localStorage）、WebAudio 音效、噗噗繪圖
*.html        每款遊戲一個檔案，canvas 或 DOM，不需外部函式庫
```

最高分只存在瀏覽器的 localStorage（鍵名開頭 `puputown.`）。

## 新增一款小遊戲

1. 複製一款遊戲的 HTML，呼叫 `MG.init({ id, title, stats })`、`MG.fit(canvas, w, h)`，用 `MG.panel` 做開始和結果畫面，`MG.record(id, score)` 記最高分。
2. 在 `index.html` 的 `GAMES` 陣列加一筆（分類、說明、縮圖 SVG、最高分格式）。
3. 在首頁「更新紀錄」加一行，結尾別忘了 ^_^。
