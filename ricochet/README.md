# 反彈神射手 · Ricochet

調角度、算反彈的射擊解謎。俯視的場地上，玩家站著不動，調好射擊角度發射：子彈撞牆會反彈、碰到斜鏡子會轉彎、穿過敵人繼續飛。用最少的子彈打倒所有敵人。
畫面全部用 Canvas 2D 程式畫（沒有圖片素材、沒有外部套件、沒有建置步驟）。
目前是**第一版（簡單版）**：敵人不會攻擊、不會動；角色和 UI 之後再調。

## 玩法
- **瞄準**：在場地上拖曳（角度跟著手指／滑鼠）。
- **微調**：↺ 逆時針、↻ 順時針，點一下 0.2°，按住越轉越快。鍵盤 ← → （或 A／D、↑ ↓）每次 0.5°，按住 Shift 0.1°。
- **發射**：「發射」按鈕或空白鍵／Enter。同一時間只有一顆子彈在飛。
- R 重來、Esc 回選關（選關畫面 Esc 回大廳）。
- 瞄準線顯示到第一次反彈，再往後一小段（淡色）。後面的路線要自己想。
- 角度：0° 朝畫面右邊，逆時針變大（量角器上的紅色弧）。手機直拿時場地會轉 90°，顯示的角度是**畫面上**的角度。
- 子彈最多反彈 6 次，第 7 次撞牆就碎掉。
- 星星：`par` 發以內清光 3 星、多 1 發 2 星、再多 1 星。過了一關才開下一關。

## 場地元素
| 元素 | 樣子 | 作用 |
|---|---|---|
| 牆 | 深紫色磚塊 | 反彈 |
| 外框 | 深色邊 | 反彈（關卡可以把某幾邊設成海綿） |
| 鏡子 | 藍色斜玻璃 | 反彈，可以擺任何角度 |
| 海綿牆 | 紫色有點點 | 吸住子彈，不反彈 |
| 炸藥桶 | 紅色有黃帶 | 子彈碰到就爆炸，範圍內的敵人和其他炸藥桶一起炸（子彈穿過去繼續飛） |
| 敵人 | 綠色小怪獸 | 被打到就倒下（子彈穿過去繼續飛） |

## 檔案
- `index.html`：版面、HUD、操作列、選關／結果畫面（CSS 在這裡）。
- `core.js`：**物理核心**：關卡轉成多邊形、射線找最先撞到的邊、反射、碰到敵人／炸藥桶、瞄準線。遊戲和解題器共用，所以解題器的答案跟實際玩一樣。
- `levels.js`：**關卡資料**（格式寫在檔案開頭）。場地固定 800×560。
- `game.js`：畫面配置（直式旋轉場地）、操作、繪圖、特效、WebAudio 音效、存檔。
- `tools/solve.mjs`：關卡解題器（不會上傳到網站）。

## 改關卡
改 `levels.js` 後一定要跑：
```sh
node ricochet/tools/solve.mjs        # 全部
node ricochet/tools/solve.mjs 7 12   # 指定關卡
```
每 0.05° 試射一發，列出最少幾發清光、每隻敵人能被打到的角度總寬、建議解法角度。打不完、子彈不夠、par 比最少發數還少時會標 ✗ 並 exit 1。
一個解法的角度窗至少 0.3° 才算（太窄玩家調不出來）。

網址加 `?lv=5` 直接進第 5 關（測試用）。主控台有 `window.__rico`（`setAngle`、`fire`、`load`）。

## 存檔
- `ricochet:v1`：`{ "best": { "<關卡序號，0 起>": 星數 } }`
- `ricochet:mute`：`"1"` 靜音
