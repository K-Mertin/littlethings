# 反彈神射手 · Ricochet

調角度、算反彈的射擊解謎。俯視的場地上，主角阿彈站著不動，調好角度開槍：子彈撞牆反彈、碰鏡子轉彎、穿過敵人繼續飛。用最少的子彈打倒所有敵人。
畫面全部用 Canvas 2D 程式畫（沒有圖片素材、沒有外部套件、沒有建置步驟）。

## 玩法
- **瞄準**：在場地上拖曳（角度跟著手指／滑鼠）。
- **微調**：↺ 逆時針、↻ 順時針，點一下 0.2°，按住越轉越快。鍵盤 ← →（或 A／D、↑ ↓）每次 0.5°，按住 Shift 0.1°。
- **發射**：「發射」按鈕或空白鍵／Enter。**H** 提示、**R** 重來、**Esc** 回選關（選關畫面 Esc 回大廳）。
- 瞄準線顯示到第一次反彈，再往後一小段（淡色）；穿過傳送門也會畫出來。後面的路線要自己想。
- 角度：0° 朝畫面右邊，逆時針變大（量角器上的紅色弧）。手機直拿時場地會轉 90°，顯示的角度是**畫面上**的角度。
- 玩家子彈最多反彈 6 次，第 7 次撞牆就碎掉。最後一隻敵人倒下時子彈就消失。
- **愛心**（預設 3 顆）：子彈反彈回來打到自己（至少彈過一次才算）、被敵人子彈打到、被炸藥桶炸到，都會少一顆。沒了就失敗。
- 星星：`par` 發以內清光 3 星、多 1 發 2 星、再多 1 星。用了提示最多 2 星。過了一關才開下一關。
- **💡 提示**：用解題器（`Core.solve`）從目前的局面找下一發，畫一條金色虛線並顯示角度。

## 回合制
玩家開一槍 → 子彈飛完 → 判定（清光就贏；打到人質、沒愛心、沒子彈就輸）→ **敵人回合**：回合數 +1，會動的牆和走路怪移到下一格，到時間的射手照順序開槍 → 換玩家。
所有東西只在回合之間動，所以同一個局面同一個角度結果永遠一樣：解題器能驗證每一關，提示也一定打得到。
瞄準時會用虛線框畫出會動的牆下一回合的位置。

## 場地元素
| 元素 | 樣子 | 作用 |
|---|---|---|
| 牆 | 依主題：石磚、深藍冰塊、鋼板、城堡磚 | 反彈 |
| 外框 | 木柵欄／雪堆／警示條／城牆 | 反彈（關卡可以把某幾邊設成海綿） |
| 鏡子 | 金屬框藍色斜玻璃 | 反彈，可以擺任何角度 |
| 海綿牆 | 紫色有洞 | 吸住子彈，不反彈 |
| 冰晶玻璃 | 白色虛線框、有裂痕 | 一打就碎，子彈直接穿過去；之後的子彈也能過。炸藥桶也炸得碎 |
| 傳送門 | 一對同顏色的漩渦 | 子彈碰到一個，從另一個飛出來，方向不變 |
| 會滑動的牆 | 有箭頭紋路的方塊 | 每回合換到下一個位置（循環） |
| 炸藥桶 | 木桶＋TNT | 子彈碰到就爆炸：範圍內的敵人、其他炸藥桶、玻璃都炸掉；也會炸到人質和主角 |
| 小雪兔（人質） | 被繩子綁住的白兔 | 打到或炸到就失敗 |
| 哥布林 | 綠色，配件隨機 | 被打到就倒下（子彈穿過去繼續飛） |
| 射手 | 橘紅色、拿小砲 | 頭上顯示幾回合後開槍；變成紅色「!」時，下一回合就會朝主角開槍，瞄準時會畫紅色警告線。敵人的子彈也會反彈（最多 3 次）、會打到其他哥布林、打碎玻璃、引爆炸藥桶 |
| 盾牌兵 | 藍灰色、戴頭盔 | 盾牌朝固定方向，從前面打會被彈開（盾牌就像鏡子）；打倒後盾牌消失 |
| 走路怪 | 紫色、穿靴子 | 每回合走到路線上的下一格；瞄準時用虛線圈畫出下一步 |
| 哥布林大王 | 戴皇冠、紅披風、大一號 | 要打好幾下（頭上的愛心）；同一發子彈來回穿過牠，每穿一次算一下；通常也會開槍 |

## 檔案
- `index.html`：版面、HUD（愛心、子彈、提示）、操作列、選關（分世界）／結果畫面（CSS 在這裡）。
- `core.js`：**物理＋回合規則＋解題**：關卡轉成多邊形、射線找最先撞到的邊、反射、傳送、玻璃、敵人／炸藥桶／人質／主角的命中、敵人回合（`enemyTurn`）、一整回合（`playTurn`）、廣度優先解題（`solve`）、瞄準線。遊戲、解題器、提示三個共用，所以答案跟實際玩一樣。
- `levels.js`：**關卡資料**＋世界清單（`LEVELS.WORLDS`）。格式寫在檔案開頭。場地固定 800×560。
- `art.js`：**美術**：主角阿彈（牛仔帽小神槍手，會眨眼、後座力、過關跳、失敗垮臉、被打到會抖）、哥布林敵人（依關卡種子隨機配色和配件，眼睛盯著主角、子彈飛的時候會害怕、被打飛轉圈冒小幽靈）、小雪兔、炸藥桶、傳送門、玻璃、會動的牆、量角器、漫畫字；四種主題場景（`camp`、`ice`、`factory`、`castle`），地板／外框／固定的牆預先畫到離屏畫布。網址加 `?theme=ice` 可以預覽主題。
- `game.js`：畫面配置（直式旋轉場地）、回合流程、操作、特效、WebAudio 音效、存檔。
- `hint-worker.js`：💡 提示在 Web Worker 裡跑解題（最後幾關要算幾秒，不會讓畫面卡住）。
- `tools/solve.mjs`：關卡解題器（不會上傳到網站）。

## 改關卡
改 `levels.js` 後一定要跑：
```sh
node ricochet/tools/solve.mjs        # 全部
node ricochet/tools/solve.mjs 7 12   # 指定關卡（全部關卡從 1 開始編號）
JSON=1 node ricochet/tools/solve.mjs # 輸出每關解法角度（自動通關測試用）
```
在每個局面每 0.1° 試射一發（照完整的回合規則），連續同一個結果的角度合成一個「角度窗」，窗至少 0.6° 才算（太窄玩家調不出來；`MIN_WIN=0.8` 可以改）。
用廣度優先找最少幾發過關。打不完、par 比最少發數還少、東西擺在牆裡時會標 ✗ 並 exit 1。
新關卡只能**加在最後面**（存檔用關卡序號記星星）。

網址加 `?lv=5` 直接進第 5 關（測試用）。主控台有 `window.__rico`（`setAngle`、`fire`、`load`、`hint`、`phase`）。
