# 深淵地牢 · Abyss Delve

回合制 Roguelike 地牢探險（向《風來的西林》、Pixel Dungeon、Brogue 致敬）。每一局的地圖、道具外觀、怪物配置都是隨機產生的，死掉就從頭開始。直接用瀏覽器打開 `index.html` 即可遊玩，不需要建置。

## 內容
- 17 層：青苔地窖（1–4）、菇菌洞窟（5–8）、熔岩鍛爐（9–12）、冰晶神殿（13–16），最後在第 17 層對決深淵之王
- 地圖產生：房間＋走廊、細胞自動機洞窟、岩漿河與石橋、冰晶柱、秘密寶庫（秘門）、怪物巢穴、商店、神秘泉水；保證樓梯一定走得到
- 視野與戰爭迷霧（陰影投射）、彩色動態光源（火把閃爍、岩漿、冰晶、發光蘑菇、祭壇）、暗角、每個生態區不同的環境粒子（灰塵、孢子、火星、雪花、虛空微光）、小地圖與大地圖
- 畫面：整層地形預先畫進快取畫布；牆面有磚縫與受光、牆頂有邊緣、牆邊有陰影，地板依生態區有石板／岩面／玄武岩／冰磚／黑曜石，加上骨頭、青苔、水窪、蜘蛛網、裂縫、旗幟、鎖鏈等裝飾；水與岩漿有流動動畫和岸邊
- 角色：程式繪製的多影格像素角色（待機、走路、攻擊），主角會換上身上的武器與護甲；怪物各有造型與動作，5 隻頭目有大型專屬造型、登場橫幅、頭目血條與狂怒第二階段；揮砍弧光、火花、死亡消散、寶物從怪物或寶箱彈出
- 5 種職業：戰士、盜賊、法師，以及解鎖後的遊俠、聖騎士，各有兩個技能
- 20 多種怪物：遠程射手、會逃跑的小偷精、召喚者、隱形的鬼火與幽影刺客、偽裝成寶箱／石像的怪物、分裂的史萊姆、成群的狼與狗頭人，以及 4 隻守層頭目
- 道具：武器、護甲、戒指、藥水、卷軸、魔杖、投擲武器、食物、金幣；藥水／卷軸／戒指／魔杖每局外觀不同，使用後才辨識；詛咒裝備
- 陷阱、秘門、毒霧／混亂／麻痺／火焰雲（高草會延燒）
- 升級時三選一天賦；靈魂石永久強化、職業解鎖、冒險紀錄（死因、種子）、每日挑戰（每天一種變化，例如玻璃大砲、精英之日、永夜）
- 耐玩度：武器／護甲符文（烈焰、冰霜、吸血、雷鳴、荊棘、再生……）與 6 種「共鳴」組合；6 種精英怪；寶箱（混著寶箱怪）；鮮血／黃金／混沌／試煉四種祭壇；20 個成就（解鎖細劍、死神鐮刀、龍鱗甲、會心之戒、符文卷軸與 5 種開局祝福）；深淵等級 0–10（打倒頭目解鎖下一級，靈魂石加成）；怪物與道具圖鑑；結算畫面（深度條、死因、本局成就）
- 離開時自動存檔（localStorage），永久死亡；舊版存檔可以直接繼續
- 鍵盤（方向鍵／WASD／數字鍵盤＋快捷鍵）與觸控（點地圖走路、長按查看、可選的方向鍵）；手機直向、橫向、平板、桌機
- WebAudio 即時合成的音效與各區域環境音樂

## 檔案
- `js/util.js` 亂數（可存檔的 sfc32）、存檔
- `js/data.js` 地形、生態區、職業、怪物、道具、天賦等資料
- `js/art.js` 道具像素圖（文字點陣）
- `js/sprites.js` 角色、怪物、頭目、寶箱、祭壇的程式繪圖與多影格快取（主角依裝備換裝）
- `js/terrain.js` 各生態區地形材質與整層地形快取（自動接牆、陰影、裝飾）
- `js/extra.js` 符文、共鳴、精英怪、寶箱、祭壇、成就、圖鑑、深淵等級、每日變化、開局祝福
- `js/gen.js` 樓層產生與連通檢查
- `js/fov.js` 視野與尋路
- `js/game.js`、`js/world.js`、`js/explore.js` 遊戲規則、戰鬥、怪物 AI、自動探索
- `js/render.js` 繪圖與特效，`js/ui.js` 介面與輸入，`js/audio.js` 音效音樂，`js/main.js` 啟動與測試介面（`window.__dg`）
