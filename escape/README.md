# 八音盒謎屋 · Music Box Manor

點擊式的密室逃脫＋推理解謎遊戲。全部畫面都用程式畫成（SVG），音樂與音效用 WebAudio 即時合成，不需要任何圖檔、音檔或外部函式庫。

## 故事

生日這天，你收到鐘爺爺寄來的綠色邀請函：「你的禮物，藏在八音盒之家最高的地方。」
可是一走進玄關，大門就自己鎖上了，爺爺也不見人影，只留下署名「X」的綠墨水字條。
解開八個房間的謎題、收集八枚音符齒輪，找出 X 的真面目吧！破完之後，爺爺還有一個藏在地底下的祕密……

## 內容

- **謎屋本篇八章**：玄關、書房、溫室、廚房、音樂室、玩具房、鐘錶工房、星空閣樓。
- **番外篇兩章**（破完本篇解鎖）：黑漆漆的地下室（點油燈、倒果汁量容量、接水管、跟著老鼠腳印找密碼）、月光庭院（過河石、螢火蟲記憶、燈籠倒影、時光寶盒）。
- **小鎮推理事件簿四件**：草莓蛋糕不見了、畫展停電之夜、鐘樓停擺之謎、車站的金懷錶（新：比對鞋印）。調查現場→從證詞找矛盾（「請等一下！」「矛盾！」大字特效）→指認犯人。
- **耐玩度**
  - 重玩任何一章，大部分謎題的答案都會**隨機改變**（雨傘數量、火車時間、水果重量、樂曲、排排坐規則、齒輪間距、星座……），提示也會跟著算出新答案。第一次玩的答案固定。
  - **⏱ 挑戰模式**：破關後可在章節卡上開啟。不能看提示、答案隨機，依時間拿金／銀／銅牌。
  - **隱藏音符**：每個房間都藏著一個金色小音符。
  - **成就** 14 個，「收藏與成就」頁可以看收集進度、挑戰紀錄和小統計。
- **畫面**：有透視感的房間（側牆、線板、木地板紋理、光影）、窗外的光束與飄浮的灰塵、會晃的吊燈與窗簾、走動的鐘擺和秒針、蒸氣、蝴蝶、螢火蟲、會甩尾巴眨眼睛的麻糬；轉向時滑動、拉近特寫時從物件位置放大；章節開場卡、拿到音符齒輪的特寫、解開謎題的印章與彩紙。
- **角色**：全部角色重新畫過，有眼珠、陰影、髮絲光澤，七種表情（平常、開心、嚇一跳、心虛、生氣、得意、崩潰），對話時會眨眼、跳出、說話時有各自音高的「嗶嗶」聲；證詞時證人直接在場景中換表情。
- **提示**：每一步都有三層提示，第三層直接給這一局的答案。
- **星星評分**：依照用時、看提示的次數（推理事件還有出示錯誤的次數）給一到三顆星。三星時間依各章份量調整（9～15 分鐘）。
- 每章自動存檔，中途離開下次可以接著玩；舊版存檔可以直接讀取（舊的齒輪機關進度會自動換成新版）。

## 操作

- 點畫面上的東西調查；左右箭頭（或鍵盤 ← →）轉向四面牆；「返回」（或 ↓）離開特寫。
- **手機直向**：場景放大顯示，左右拖曳就能看到整面牆（下方小條顯示目前位置）。
- 點道具拿在手上，再點畫面使用；拿著道具點另一個道具可以組合；同一個道具點兩下可以仔細查看。
- 右上角：燈泡是提示、本子是偵探手帳（關於 X 的線索）、喇叭是靜音。選單裡可以關掉環境動畫（較舊的手機會自動切換省電模式）。
- 支援滑鼠與觸控，手機直向、橫向、平板與電腦都能玩。

完整解答（有雷）在 `tools/WALKTHROUGH.md`。
