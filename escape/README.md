# 八音盒謎屋 · Music Box Manor

點擊式的密室逃脫＋推理解謎遊戲。全部畫面都用程式畫成（SVG），音樂與音效用 WebAudio 即時合成，不需要任何圖檔、音檔或外部函式庫。

## 故事

生日這天，你收到鐘爺爺寄來的綠色邀請函：「你的禮物，藏在八音盒之家最高的地方。」
可是一走進玄關，大門就自己鎖上了，爺爺也不見人影，只留下署名「X」的綠墨水字條。
解開八個房間的謎題、收集八枚音符齒輪，找出 X 的真面目吧！

## 內容

- **謎屋八章**：玄關、書房、溫室、廚房、音樂室、玩具房、鐘錶工房、星空閣樓。每個房間四面牆可以轉向、可以拉近看細節，道具能查看、組合、使用。
- 謎題種類：線索密碼、顏色順序、滑動拼圖、光線與鏡子、天平推理、時鐘、密碼轉盤、排排坐邏輯題、點燈、齒輪咬合、行星順序、星座觀測……最後還要說出 X 是誰。
- **小鎮推理事件簿**：三件推理事件（草莓蛋糕不見了、畫展停電之夜、鐘樓停擺之謎）。先調查現場收集證物，再從證詞裡找出矛盾、出示證物，最後指認犯人。
- **提示**：每一步都有三層提示，第三層直接給答案。卡關不用怕。
- **星星評分**：依照用時、看提示的次數（推理事件還有出示錯誤的次數）給一到三顆星。
- 每章自動存檔，中途離開下次可以接著玩；可從章節選擇重玩任何已解鎖的章節。

## 操作

- 點畫面上的東西調查；左右箭頭（或鍵盤 ← →）轉向四面牆；「返回」（或 ↓）離開特寫。
- 點道具拿在手上，再點畫面使用；拿著道具點另一個道具可以組合；同一個道具點兩下可以仔細查看。
- 右上角：燈泡是提示、本子是偵探手帳（關於 X 的線索）、喇叭是靜音。
- 支援滑鼠與觸控，手機直向、橫向、平板與電腦都能玩。

完整解答（有雷）在 `tools/WALKTHROUGH.md`。
