# 八音盒謎屋 · Music Box Manor

點擊式的密室逃脫＋推理解謎遊戲。全部畫面都用程式畫成（SVG），音樂與音效用 WebAudio 即時合成，不需要任何圖檔、音檔或外部函式庫。

## 故事

生日這天，你收到鐘爺爺寄來的綠色邀請函：「你的禮物，藏在八音盒之家最高的地方。」
可是一走進玄關，大門就自己鎖上了，爺爺也不見人影，只留下署名「X」的綠墨水字條。
解開八個房間的謎題、收集八枚音符齒輪，找出 X 的真面目吧！破完之後，爺爺還有一個藏在地底下的祕密……

## 內容

- **謎屋本篇八章**：玄關、書房、溫室、廚房、音樂室、玩具房、鐘錶工房、星空閣樓。
- **番外篇兩章**（破完本篇解鎖）：黑漆漆的地下室（點油燈、倒果汁量容量、接水管、跟著老鼠腳印找密碼）、月光庭院（過河石、螢火蟲記憶、燈籠倒影、時光寶盒）。
- **小鎮推理事件簿五件**：草莓蛋糕不見了、畫展停電之夜、鐘樓停擺之謎、車站的金懷錶（比對鞋印）、音樂會的走音事件（新：看照片找出不對勁的地方）。調查現場→從證詞找矛盾（「請等一下！」「矛盾！」大字特效）→指認犯人。現場的人物都是全身的小人，會呼吸、晃動、眨眼，點他們說話時還會跳一下。
- **耐玩度**
  - 重玩任何一章，大部分謎題的答案都會**隨機改變**（雨傘數量、火車時間、水果重量、樂曲、排排坐規則、齒輪間距、星座……），提示也會跟著算出新答案。第一次玩的答案固定。
  - **挑戰模式**：破關後可在章節卡上開啟。不能看提示、答案隨機，依時間拿金／銀／銅牌。
  - **今日謎題**（新）：破完第一章後標題畫面會出現。每天從破過的房間挑一間、用日期算出一組答案（同一天大家的題目一樣），不能看提示、拿獎牌，還會記錄連續天數。
  - **隱藏音符**：每個房間都藏著一個金色小音符。
  - **成就** 18 個（含一個隱藏成就），圖示全部用 SVG 畫，沒有表情符號字型的裝置也看得到。「收藏與成就」頁可以看收集進度、挑戰紀錄、今日謎題連續天數和小統計。
- **精緻畫風**（新）：每個房間有固定的主光源（轉向時光從左、右或正面照來，陰影也跟著偏）；壁紙有細緻花樣與頂端飾帶、灰泥斑駁與紙紋，天花板有齒飾線板、腰線與踢腳板有線腳；木頭家具自動帶木紋、所有有輪廓的物件都有受光漸層；木地板有木紋、接縫與釘子，磁磚有縫線與反光；線條改成粗細分明（外框粗、細節細）。門有門框角花、鉸鏈與門把底座；窗外有遠山、樹林與籬笆，窗簾有布紋、皺褶與吊環；畫框有角花與畫布紋；書有燙金書背；植物葉子有葉脈。每個房間都多了有細節的擺設（掛畫、小書架、鏡子、掛鉤、編織籃、地毯、茶壺、設計圖、懷錶板、旅行箱……），推理事件的現場、標題畫面的八音盒之家（魚鱗瓦、百葉窗、花台、常春藤、路燈）與章節卡的花飾也一起重畫；人物多了髮絲、衣服皺褶與布紋、眼睛虹膜光澤。這些質感都是事先定義好的漸層與花紋（不加濾鏡），效能跟以前差不多。
- **畫面**：月光庭院整個重畫（銀河、遠山上的八音盒之家、樹籬與木柵欄、睡蓮池塘、石燈籠、掛鞦韆的老樹）；溫室看得到玻璃外的花園，多了花架與玫瑰棚；鐘錶工房牆上有慢慢轉的大齒輪組、工具櫃；地下室多了木樑、葡萄酒架、掛著的香草與大蒜、鐵窗月光。有透視感的房間（側牆、線板、木地板紋理、光影）、窗外的光束與飄浮的灰塵、會晃的吊燈與窗簾、走動的鐘擺和秒針、蒸氣、蝴蝶、螢火蟲、會甩尾巴眨眼睛的麻糬；轉向時滑動、拉近特寫時從物件位置放大；章節開場卡、拿到音符齒輪的特寫、解開謎題的印章與彩紙。
- **角色**：全部角色重新畫過，有眼珠、陰影、髮絲光澤，七種表情（平常、開心、嚇一跳、心虛、生氣、得意、崩潰），對話時會眨眼、跳出、說話時有各自音高的「嗶嗶」聲；證詞時證人直接在場景中換表情。
- **提示**：每一步都有三層提示，第三層直接給這一局的答案。
- **星星評分**：依照用時、看提示的次數（推理事件還有出示錯誤的次數）給一到三顆星。三星時間依各章份量調整（9～15 分鐘）。
- 每章自動存檔，中途離開下次可以接著玩；舊版存檔可以直接讀取（舊的齒輪機關進度會自動換成新版）。

## 操作

- 點畫面上的東西調查；左右箭頭（或鍵盤 ← →）轉向四面牆；「返回」（或 ↓）離開特寫。
- **手機直向**：場景放大顯示，左右拖曳就能看到整面牆（下方小條顯示目前位置）。
- 點道具拿在手上，再點畫面使用；拿著道具點另一個道具可以組合；同一個道具點兩下可以仔細查看。
- 右上角：燈泡是提示、本子是偵探手帳（關於 X 的線索）、喇叭是靜音。選單裡可以關掉環境動畫。
- **效能**：背景小動畫都只動 transform／opacity（各自一層，不會讓整個場景重畫）；標題畫面與手機上的環境動畫由「節拍器」統一每秒更新 30 次；裝置太吃力時會自動分兩段降級（先拿掉灰塵星光，再停掉全部環境動畫）。
- 支援滑鼠與觸控，手機直向、橫向、平板與電腦都能玩。

完整解答（有雷）在 `tools/WALKTHROUGH.md`。
